# 主检查清单

> 这是索引，不代替总手册、当前阶段验收或真实证据。只有实际验证后才勾选。

## 启动与治理

- [ ] AI 已代办创建目录、Git 初始化、模板复制和状态检查
- [ ] 若要求用户介入，确因权限/登录/界面限制且只给了一个最小动作
- [ ] 项目根目录没有多套一层模板文件夹
- [ ] Git 在任何项目产物前初始化
- [ ] 文档与代码目录分离
- [ ] 当前阶段状态文件准确
- [ ] 每次开工已读总手册、项目手册和状态文件
- [ ] 每个子阶段先报告，用户批准后才本地归档
- [ ] 推送、部署和生产操作取得单独授权

## 决策与规划

- [ ] 立项基于证据，范围和非目标明确
- [ ] 优秀案例与官方资料标注来源和日期
- [ ] 唯一技术栈有评分、淘汰理由、成本和退出路径
- [ ] 项目专属规范手册已生成并获批
- [ ] 总计划、设计规范、架构规则、安全、测试和数据治理已获批

## 顺序门禁

- [ ] 前端设计获批后，前端编码已全部完成
- [ ] 前端完成后，数据库设计获批且数据库编码已全部完成
- [ ] 数据库完成后，后端设计获批且后端编码已全部完成
- [ ] 集成和跨层总审查无阻塞项
- [ ] 每一层都没有越过“设计确认 → 编码完成”门禁

## 实现与质量

- [ ] 开发顺序为前端、数据库、后端、联调
- [ ] 每项需求有正常、失败、未登录、越权和边界证据
- [ ] 密钥、个人数据和生产凭据未进入仓库或日志
- [ ] 认证、授权和数据库保护分别验证
- [ ] 测试、静态检查和生产构建有当前输出
- [ ] Critical/High 安全问题为零或发布被阻断
- [ ] 以上阶段全部只使用合成数据

## 发布与运营

- [ ] 开发、预览、生产环境分离
- [ ] 备份恢复和回滚已真实演练
- [ ] 生产迁移先备份、后迁移、再冒烟
- [ ] 监控、告警、Runbook、事故和维护记录齐全
- [ ] 费用上限、速率限制和停机开关可用
- [ ] 真实数据在项目验收后才经备份、试导入和单独批准进入生产
- [ ] 真实数据、秘密、日志和数据库导出未进入任何 Git 历史
- [ ] GitHub 仓库是 Public，README 提供公开体验 URL
- [ ] 未登录访客可从全新浏览器直接打开并体验公开 URL
