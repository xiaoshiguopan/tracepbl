# 史证工坊测试策略

> 文档版本：0.1
> 更新日期：2026-08-31
> 状态：已批准归档

## 1. 当前事实、计划与缺口

- **已有**：截至本文件日期，仓库只有治理和规划文档，没有应用代码、测试、依赖或可执行测试脚本。
- **计划**：脚手架获批后建立 Vitest、React Testing Library、MSW、Playwright、Testcontainers 和静态检查组成的分层测试体系。
- **缺口**：所有产品行为、性能、安全、浏览器兼容、数据库迁移、模型质量和公开可访问性当前均未验证；不得写成“已通过”。

## 2. 测试层次与责任

| 层次 | 主要对象 | 必须覆盖 | 计划工具 |
|---|---|---|---|
| 静态 | 全仓库 | 格式、lint、严格类型、依赖方向、秘密扫描 | ESLint、TypeScript、专用扫描 |
| 领域单元 | `packages/domain` | 状态回退、证据门禁、权限/TTL/费用/幂等策略 | Vitest |
| 组件 | Web 组件 | 可访问名称、键盘、所有系统状态、表单恢复 | RTL + Vitest |
| 契约 | contracts、客户端、API | Zod/OpenAPI 输入输出、错误和版本兼容 | Vitest |
| 数据库 | Schema/仓储/迁移 | 约束、事务、隔离、级联删除、向量关联 | Testcontainers PostgreSQL/pgvector |
| 集成 | API/Worker/外部适配 | 授权、队列、重试、模型/存储失败、费用停止 | Vitest + MSW/fake provider |
| E2E | Demo 与完整模式 | 主链、取消、失败恢复、导出、清除/删除 | Playwright |
| 人工 | 内容与体验 | 历史准确性、教师可用性、中国网络、屏幕阅读器 | 评审记录与证据截图（仅合成数据） |

自动化必须验证确定性规则；历史专业判断、课堂适用性和真实网络体验需要人工复核，不能用模型测试替代。

## 4. 每项行为的通用测试维度

每个可交付行为至少考虑：正常、失败、未认证、已认证但无权、空值、最大/最小边界、恶意输入、重复/并发、超时/取消、刷新恢复、上游变化后的状态回退。与该行为无关的维度在测试说明中写明“不适用”，不能静默遗漏。

关键规则必须直接测试而非依赖覆盖率推断：资源授权、来源定位、许可阻断、审计阻断、教师批准、TTL/删除、费用限制、Agent 工具权限。

## 5. 测试数据与外部服务

- 阶段12批准前只使用版本化合成数据或许可明确的公开材料；“给真实数据改名字”不算合成。
- fixture 有来源/生成方式、许可、用途、版本和预期结果；故意恶意样本明确标识并安全存储。
- 默认测试使用确定性 fake/stub，不调用收费 AI API。模型选择依据公开资料；本项目不把实时 AI API 质量测试作为阶段门禁。
- 如未来确需受控在线冒烟测试，必须单独授权、使用专用低权限密钥、严格预算且不上传禁止数据；其不稳定结果不得阻塞普通本地开发。

## 6. CI 与合并/归档门禁

计划命令依次为：

1. `npm run format:check`
2. `npm run lint`
3. `npm run typecheck`
4. `npm run test`
5. `npm run test:integration`
6. `npm run test:e2e`
7. `npm run build`

代码阶段只运行与当前层相符的已实现子集，但不得以“未建脚本”假装通过；最终质量阶段全部为必过。失败、跳过、重试后通过和环境限制都必须如实报告。公共分支保护和 CI 工作流需在用户授权 GitHub 操作后配置。

覆盖率用于发现空白而非凑数：领域/安全关键分支要求直接测试；实现后整体行和分支覆盖目标为 80%，未达须说明缺口，达到也不替代行为验收。

## 7. 证据格式与缺陷规则

每份阶段报告记录：提交/工作区基线、环境、完整命令、退出码、测试数量、失败/跳过、产物位置、人工步骤和未测风险。截图只使用合成数据，并配文本证据。

- 缺陷按数据/安全、核心正确性、恢复可靠性、可访问性、维护性排序。
- 阻断级缺陷不得带病归档或发布；修复应有能因原问题失败的回归测试。
- 不删除、弱化、跳过有效测试制造通过。偶发测试先定位原因；禁止无限重跑。

## 8. 发布前人工清单

- 从全新环境按 README 启动；Pages URL 由中国网络实际抽样。
- 仅键盘完成主链，检查焦点、缩放、屏幕阅读器关键路径。
- 历史教师复核示范课程的准确性、适龄性和量规可用性。
- 验证 Demo 标签、本地清除、完整模式删除、费用停止、外部失败、回滚与恢复演练。
