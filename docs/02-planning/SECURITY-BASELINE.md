# 史证工坊安全基线

> 文档版本：0.2
> 更新日期：2026-09-03
> 状态：0.2 已批准归档
> 基准：参考 OWASP ASVS 5.0 的风险导向要求；不宣称认证或完整符合

## 1. 保护对象、参与者与入口

保护对象包括：来源与许可元数据、教师工作内容、本机 workspace 边界、模型/数据库密钥、费用额度、审计记录、公开仓库与发布链。

| 参与者 | 权限边界 |
|---|---|
| Demo 访客 | 只操作自己浏览器中的公开/合成数据；无服务端秘密和持久身份 |
| 当前本机教师 | 只通过绑定 localhost 的完整模式访问一个内部 workspace；可列出自己的任务，不能跨 workspace |
| API/Worker 服务身份 | 按职责访问数据库、模型和存储；彼此不共享万能凭据 |
| 仓库维护者 | 运维身份，不是产品角色；其操作通过平台权限和审计管理 |

入口包括公开页面、localhost API、粘贴文本、URL/来源输入、异步任务队列、模型输出、数据库、CI/CD 和依赖供应链。v0.1 不含文件摄取、账户、分享、管理后台、邮件、支付、入站 webhook 或通用定时业务；只允许删除到期清理这一维护作业。

## 2. 信任边界与强制检查

```text
浏览器（不可信） -> localhost API（workspace/资源授权/校验/限额） -> PostgreSQL
API -> Worker（签名任务/幂等） -> 模型或检索服务（外部不可信）
模型/检索结果 -> 契约校验 -> 领域门禁 -> 教师明确批准 -> 导出
GitHub 贡献/依赖（不可信） -> CI 最小权限验证 -> Pages 发布
```

| 流程 | 主要威胁 | 必须控制 |
|---|---|---|
| 本机 workspace 访问任务 | task ID 猜测、跨作用域引用、意外远程暴露 | 仅监听 loopback、固定 workspace 上下文、服务端逐资源归属检查、默认拒绝、日志脱敏 |
| 输入史料/URL | XSS、SSRF、恶意文件、版权误用 | 类型/大小校验、内容净化、URL允许策略、私网/重定向/DNS复核、许可状态 |
| AI/RAG/Agent | 提示注入、越权工具、伪造引用、费用滥用 | 数据/指令分离、工具允许清单、最小权限、结构校验、引用门禁、预算/超时/停止 |
| 异步任务 | 重放、重复写、无限重试 | 签名或可信队列、幂等键、有限重试、死信/终态、取消 |
| 导出/删除 | IDOR、残留、误操作 | 重新授权、明确确认、级联清理、审计；过期后不恢复 |
| CI/发布 | 恶意 action、secret 泄露、供应链替换 | action 固定完整 SHA、最小 token 权限、依赖锁定、秘密扫描、受控环境 |

## 3. 身份与资源授权

- 无账户不等于无授权。当前完整模式只允许本机单用户、一个内部 workspace；task ID、URL 可见部分和客户端状态均不能单独授权。
- 每次读、写、导出、取消和删除都在服务端校验 workspace、对象归属、状态与动作权限；默认拒绝。
- 无权访问与不存在使用不泄露资源存在性的响应。高影响动作不能只依赖前端隐藏按钮。
- 阶段 7 决定当前不采用 RLS：单用户 localhost 的复杂度收益不足。若出现第二用户、远程监听、分享或云部署，必须阻断上线并重做认证、租户和 RLS；API 用例层授权始终不可省略。
- 未删除任务持续保存；显式删除立即隐藏，24 小时内只允许撤销，之后彻底清除。

## 4. 输入、输出与浏览器安全

- 所有外部输入有长度、类型、枚举、格式和业务约束；数据库使用参数化查询，命令/模板不得拼接不可信文本。
- 用户或模型 HTML 默认当纯文本；必须渲染富文本时使用允许清单净化并部署严格 CSP。不得使用未净化 `dangerouslySetInnerHTML`。
- 改变状态的浏览器请求采用明确 Origin/CORS 允许清单和 CSRF 防护；不使用 `*` 搭配凭据。
- 服务端取 URL 默认禁止；确需来源抓取时仅允许 HTTP(S)，限制端口、重定向、解析后 IP 和响应大小，阻止 localhost、私网、链路本地及云元数据地址，并在每次重定向后复核。
- v0.1 不接收文件上传；URL/文本按长度、scheme、目标地址、内容和权利边界校验。未来若加入文件摄取，必须先重做类型、大小、隔离存储和内容检查设计。
- 跳转目标使用内部路由或允许清单；错误和下载文件名做上下文编码。

## 5. 秘密、日志、缓存与第三方

- 密钥只来自本地未跟踪环境或平台 secrets；绝不进入 Git、前端包、fixture、截图、错误响应或测试输出。
- `DATABASE_URL` 与模型 Key 分别最小授权并可独立轮换；泄露即撤销/轮换、查日志和历史、记录影响。当前不需要对象存储凭据。
- 日志只保留诊断所需元数据，不记录 capability、Cookie、Authorization、完整史料/提示词或个人数据。审计记录与调试日志分离。
- 敏感响应设不缓存；共享缓存键必须包含安全作用域，清理任务同时清除派生缓存和向量。
- 传给模型提供商的内容先最小化；实际数据保留、训练和跨境条款在启用前复核并取得用户批准。

## 6. 滥用、供应链与恢复

- API 按 workspace、loopback/IP、任务设置速率、并发、大小、Token、次数和金额上限；超限安全失败并保留已完成工作。
- 外部调用有连接/总超时、有限指数退避、熔断和人工重试；不得因失败无限生成任务。
- 锁定依赖，审查许可和维护状态；CI 第三方 action 固定完整提交 SHA、默认只读权限，发布权限与普通测试分离。
- 本地逻辑备份放在仓库外、限制访问并做恢复演练；恢复后删除清单优先，不能复活已过宽限的任务。生产目标在上线审批前重新确认。
- 事故先隔离入口、撤销密钥、停止相关 Worker/发布，再保存不含敏感内容的证据、评估范围、修复和复盘。

## 7. AI/Agent 特有基线

- 系统指令、工具定义与检索内容分层；网页和用户文本永远不能提升权限或改写硬规则。未来文档/OCR 输入同样适用，但当前不实现。
- Agent 只见完成当前步骤所需的最小数据和工具；默认只读，写操作逐项由应用层授权和校验。
- 模型不能自行批准史料、宣称许可成立、放行审计、删除数据或提高预算。
- 输出必须满足版本化结构；引用逐条验证来源 ID 与定位。验证失败进入“待复核/阻断”，不得猜测补齐。
- 保存模型、提示模板、工具调用、关键输入摘要、费用和结果状态的审计信息；不保存禁止数据。

## 8. 安全验证和例外

发布门禁至少包含：权限负向测试、URL/文本输入输出、SSRF/重定向测试、秘密扫描、依赖审计、CSP/CORS/CSRF 检查、速率/费用/取消测试、删除与跨任务隔离测试、Agent 越权/提示注入测试、备份恢复演练。

任何未满足项必须在变更记录中写明资产、威胁、补偿控制、风险所有者、到期日和批准者；阻断级问题不得以例外发布。
