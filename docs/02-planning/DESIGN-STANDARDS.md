# 史证工坊设计标准

> 文档版本：0.1
> 更新日期：2026-08-31
> 状态：已批准归档
> 适用范围：后续前端设计、实现与验收；本文件不规定具体页面或视觉稿

## 1. 体验原则

1. **证据先于生成**：每个结论都能回到来源、定位、版本、价值与局限；“没证据”必须可见。
2. **教师拥有最终决定权**：AI 只建议，教师批准、退回、编辑、导出和删除；不得用默认按钮诱导批准。
3. **诚实状态**：候选、已核验、待复核、失败和未知不得用同一种成功样式。
4. **渐进清晰**：先显示当前必做任务，再提供证据细节；不能以简洁为由隐藏许可、来源或阻断原因。
5. **可恢复**：耗时操作可取消、失败可重试、编辑不因刷新或单次外部失败丢失。
6. **Demo 不冒充在线服务**：公开页面明确说明数据保存在本机浏览器、使用公开/合成数据、未连接在线 AI 和数据库。

## 2. 信息层级与一致性

- 全产品使用同一条主链：背景 → 问题 → 史料 → 论断/证据 → 活动/支架 → 量规 → 审计 → 教师批准/导出。
- 每一步固定呈现：当前位置、完成条件、阻断原因、下一安全动作、返回上游的影响。
- 同一对象在列表、详情、审计和导出中使用一致名称、状态和 ID；状态文字不能只靠颜色区分。
- 来源定位、许可限制、教师批准和审计阻断是一级信息，在窄屏也不得隐藏。
- 删除、覆盖、重跑、批量退回等高影响操作必须说明对象、影响和恢复可能性。

## 3. 响应式与无障碍基线

目标为 WCAG 2.2 AA；这是设计和测试目标，不代表当前已认证。

- 从窄屏开始设计，内容在 320 CSS px 宽度和 200% 文本缩放下仍可阅读和操作；不依赖横向滚动完成主任务。
- 所有功能可仅用键盘完成；焦点顺序符合视觉顺序，焦点清晰且不被固定层遮挡。
- 表单控件有持久标签、说明和与字段关联的错误；占位文字不代替标签。
- 正文与背景对比度至少 4.5:1，大文字至少 3:1；非文本控件和焦点指示至少 3:1。
- 指针目标尽量不小于 24×24 CSS px；密集证据图中提供等价列表/详情操作。
- 图标有文字或可访问名称；图表、关系图和颜色状态有文本等价物。
- 动画服从“减少动态效果”，不使用闪烁；自动更新区域避免抢走焦点并用适当 live region 通知。
- 身份验证并非 v0.1 范围；未来若加入，不得把认知测试作为唯一登录路径。

## 4. 必须设计的系统状态

| 状态 | 必须让用户知道 | 必须提供 |
|---|---|---|
| 初始/空 | 为什么为空、从哪里开始 | 单一主动作和示例 |
| 加载/排队 | 正在做什么、是否仍在运行 | 进度或不确定说明、取消入口 |
| 部分成功 | 哪些成功、哪些未完成 | 分项状态和安全重试 |
| 外部失败/超时 | 失败来源和数据是否保留 | 重试、稍后继续或手工路径 |
| 校验失败 | 精确字段/规则和修复方法 | 就地错误、聚合摘要、保留输入 |
| 无权限/非当前任务 | 不能访问且不泄露对象存在性 | 返回安全起点 |
| 阻断 | 哪条证据/许可/审计规则未满足 | 定位上游问题，不提供绕过 |
| 成功 | 完成了什么、保存在哪里 | 下一步、查看证据或撤销（若安全） |
| 已过期/已删除 | 数据不再可用 | 新建任务；不承诺恢复 |

前端设计必须覆盖正常、空、加载、失败、无权限、边界、重复提交和恢复，不得只画“理想成功页”。

## 5. 视觉系统约束

- 后续阶段定义语义设计令牌：背景、表面、正文、弱化、边框、主操作、信息、成功、警告、危险、焦点；组件不得散落硬编码颜色。
- 使用 `rem` 和流式布局；间距以 4px 基准形成有限梯度，具体令牌在阶段5批准。
- 中文正文优先系统无衬线字体栈，证据原文可使用适读的衬线备选；不得仅为装饰加载大型字体。
- 标题层级连续；正文行宽、行高适合长中文史料，引用与分析视觉上可区分但不牺牲复制能力。
- 图标来自单一、许可清楚的图标系统；不把 emoji 当作关键状态图标。
- 动效只解释状态变化，持续时间短且可关闭；不得用动效掩盖等待或阻断。

## 6. 文案、数字与本地化

- 默认界面语言为简体中文，技术错误转成教师可理解的行动建议，同时保留可复制的追踪 ID。
- 使用中国时区语境时明确 `北京时间`；存储与接口时间采用 ISO 8601/UTC，界面显示完整日期以避免歧义。
- 数字使用中文环境分组；费用始终显示币种和计费口径，如 `¥0.03/次（估算）`，估算不得写成实付。
- 删除、授权、AI 生成、来源许可等文案使用准确动词，不使用“永久安全”“绝对正确”等无法证明的承诺。
- 引用保持原文语言和定位；翻译、节录、OCR 与模型摘要必须标注加工类型。

## 7. 禁止的设计捷径

- 不以颜色、悬停、图标或动画作为唯一信息通道。
- 不隐藏错误、不自动批准 AI 输出、不把未知状态显示为通过。
- 不用假在线数据库、假实时 AI、虚构教师评价或虚构来源增强 Demo。
- 不在不可逆操作上使用预勾选或模糊确认；不制造暗黑模式诱导上传真实数据。
- 不为桌面大屏牺牲手机浏览，也不为手机简化而移除证据与权限信息。

## 8. 验证与来源

后续验收至少包括键盘全流程、焦点可见性、320px/200% 缩放、对比度自动检查、屏幕阅读器关键流程人工抽查，以及所有系统状态的组件或 E2E 证据。
