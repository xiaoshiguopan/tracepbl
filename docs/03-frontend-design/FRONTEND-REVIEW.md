## 2. 第一性原理重建

### 2.1 教师最终结果

教师在无账号、当前任务隔离和明确数据边界下，把一个历史主题收束为问题，审阅权威来源候选，建立史料价值与局限、主张—证据、活动、支架和量规，通过不可绕过的审计，逐项批准后生成本地“可试教候选”。视觉入口必须让人感到历史的厚度，但不能延迟、掩盖或替代上述工作。

### 2.2 绝不能被 UI 改写的不变量

1. 核验、权利、教师批准、审计通过和可试教候选是五种不同事实。
2. AI 艺术化画面和合成教学状态不是史料；史料本体、出处、版本、编号和引文不得合成。
3. 未知、外部失败、离线和超时不能变成通过；上游改变必须使受影响下游待复核。
4. 前端隐藏、禁用、路由守卫、task ID 和 Mock 只改善体验，不是真正授权。
5. 来源、许可、批准和阻断在桌面/手机、缩放和键盘路径中都不能消失。
6. P00 混合 3D 与动画是四级可降级增强层；项目全程无声；页面从第一帧可一次点击进入，失败不影响主链；技术原型通过不等于最终视觉通过。
7. 教师编辑和最近安全状态优先保留；批准、删除、核验、审计和导出不得乐观假成功。

### 2.3 主要失败

本轮重新演练：空输入/空候选、校验失败、3D 上下文/媒体解码/艺术图或本机存储失败、低帧率、再次访问、部分来源失败、引文冲突、权利未知、重复提交、异步超时/取消、离线、跨任务/不可用、上游改变、批准过期、导出失败、清除未确认、长内容、320px、键盘/焦点、reduced-motion、自动播放被阻止，以及这些状态的组合。
