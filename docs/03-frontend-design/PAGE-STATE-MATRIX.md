## 通用验收断言

- 每页标题、主状态和主动作在 320 CSS px 及 200% 文本缩放下可达；来源状态、许可、批准和阻断不因断点消失。
- 每次用户触发异步更新都有文本反馈；自动更新不抢焦点，必要时用 `aria-live="polite"`。
- 加载骨架只表示结构，不伪造内容；系统失败写清“发生什么、保留什么、下一步”。
- 所有页面均有首屏可见的演示边界入口和任务状态入口，但不重复冗长说明。
