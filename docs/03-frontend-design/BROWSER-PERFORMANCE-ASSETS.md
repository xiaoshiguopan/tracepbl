# 浏览器、性能、动效、音频与资产基线

> 版本：0.1
> 日期：2026-08-31
> 状态：阶段 5 已批准归档
> 边界：前端可观察目标；具体构建配置在阶段 6 验证

## 1. 目标浏览器

以公开 Pages Demo 的访问目标为准：当前稳定版及前两个主要版本的 Chrome、Edge、Firefox、Safari；iOS Safari 与 Android Chrome 的常见稳定版本进行核心查看/轻编辑抽查。Internet Explorer 不支持。实际最低版本需在阶段 6 依据 Vite 输出、依赖兼容和浏览器实测冻结。

浏览器不支持 IndexedDB、自动播放、View Transition、容器查询或某种图像格式时必须渐进降级；核心闭环不能依赖实验性 API。

## 2. 首屏与交互预算

| 指标 | 设计预算 | 失败时优先动作 |
|---|---:|---|
| P00 首屏 HTML/真实文字可见 | 不等待艺术图或音频 | 先显示纯色暗场与文字 |
| 首次主操作可用 | 首帧/脚本初始化后立即；不等待 5—7 秒动画 | 关闭装饰动画初始化 |
| P00 主背景派生图片 | 桌面首选 ≤ 450 KB；移动 ≤ 220 KB | 更强压缩、不同裁切、静态渐变替代 |
| 首屏关键字体 | 0 个阻塞网络字体 | 使用系统字体栈 |
| 初始 JS（gzip，目标） | ≤ 180 KB | 路由分包、删除非必要可视化/动效代码 |
| 可选 3D 运行时代码 | 不进入初始关键包；按能力和空闲时机加载 | 使用轻量动态/静态终帧 |
| P00 完整增强媒体总传输 | 桌面目标 ≤ 4.5 MB；移动完整体验不默认加载 | 降码率、短序列、轻量动态或静态终帧 |
| P00 移动轻量媒体总传输 | 目标 ≤ 1.8 MB | 使用 ≤ 220 KB 静态派生图 |
| 3D 首个稳定增强帧 | 参考桌面网络/设备目标 ≤ 2.5s；期间 UI 已可用 | 超时不再升级，保持当前安全层级 |
| 单路由追加 JS（gzip，目标） | 常规 ≤ 80 KB；关系图按需加载 | 列表为默认，图形视图延迟加载或关闭 |
| 布局偏移 | 不因图片、骨架、字体出现明显跳动 | 固定媒体比例、系统字体、稳定骨架 |
| 长任务反馈 | 2 秒内状态；30 秒提供取消 | 本地占位不冒充进度 |

预算是进入编码阶段的门槛目标，不是当前实测结果。最终以构建分析与真实浏览器记录为准。

## 3. 图像策略

- AI 艺术图与真实史料图分目录、分组件、分标签；艺术图文件名含 `art-direction`/`illustration`，史料图含来源 ID 和权利记录。
- P00 使用 `<picture>` 概念提供桌面/移动裁切与现代格式，保留 JPEG/PNG 降级；不在 CSS 中嵌入超大 base64。
- 预渲染人物主镜头、实时空间资产、静态终帧和 UI 分开打包；浏览器先取得 UI 与静态终帧，再按能力升级，不能为判定 3D 能力先下载完整媒体。
- 预渲染片段必须提供桌面与移动/低带宽派生版本、首帧 poster 和明确尺寸；移动默认轻量动态，不请求陀螺仪权限。
- 首屏背景设置固有宽高/比例，失败时显示 `narrative-void` + 可读标题，不显示破图图标。
- P01—P11 不预加载电影背景。真实史料图只有许可允许且进入视口时才加载，并有尺寸、alt、来源和权利说明。
- 不热链馆藏图片；不从搜索缩略图或生成图中提取“史料”。

## 4. 混合 3D、动效性能与降级

- P00 按 `HYBRID-3D-OPENING-SPEC.md` 分为预渲染人物主镜头、简化空间/深度层、受控灯火/尘埃和残卷转场；不做全实时高精角色、自由漫游、无限粒子、整屏高半径实时模糊或鼠标追光。
- Canvas/媒体是独立装饰层；主内容独立于它，3D 初始化、上下文丢失或媒体解码异常不会挡住链接、滚动或焦点。
- 鼠标/触摸视差设位移上限并按帧率/设备能力关闭；不因追踪输入持续触发布局或 React 树重渲染。
- 页面不可见时暂停 `requestAnimationFrame`、预渲染媒体和音频，并释放非必要 GPU 工作；用户滚动或导航时收束到最终状态，不强制播完。
- 状态变化微动效 120—220ms；阻断/错误不摇晃；超过 5 秒的自动视觉变化必须可暂停，本项目仅 P00 有此情况。
- `prefers-reduced-motion` 直接使用最终静态帧；不只是把 7 秒缩成 1 秒。
- 首次访问播放一次；再次访问停在动态终态。只有用户主动“重看序章”才重播，返回 P00 不自动重启媒体。

四级运行梯：完整混合 3D → 轻量动态 → 静态终帧 → 纯色安全首屏。能力探测必须以可观察运行质量为准，不能只看设备型号；持续低帧率、明显长任务、上下文丢失、节省数据、reduced-motion 或资源超时均触发降级。具体阈值在技术原型中以目标设备实测冻结，不能在设计阶段伪造通过值。

## 5. 音频策略

- 单一环境声轨，优先短、可无缝循环、无语音与突发峰值；正式素材必须有明确许可和来源记录。
- 默认偏好为开；浏览器阻止自动播放时，在首次用户激活后尝试。`play()` 失败只更新控件状态，不阻塞页面或重复弹窗。
- 声音开关有文字可访问名称和 `pressed` 状态；本机只保存开/关与音量偏好，不保存指纹或跨站标识。
- 页面隐藏立即暂停；重新显示不突然从高音量恢复。静音和播放之间做极短淡入淡出，避免爆音。
- 音频不进入初始关键加载路径；网络慢/离线时不反复请求。

## 6. 长内容与列表

- 候选 ≤ 50 条使用分页/分段渲染；超过 50 条先验证 `content-visibility` 或虚拟化必要性。虚拟化若破坏读屏、查找或焦点恢复，回退分页。
- 史料长文只渲染当前展开区；不把许可未知全文载入隐藏 DOM。
- 图形关系视图按需加载；等价列表始终先可用。图形达到 100 节点前必须重新评估，否则 v0.1 先限制可视概览，不改变数据真相。
- 搜索输入做合理防抖但保留即时清除；结果更新不抢焦点。

## 7. 路由、刷新与 Pages

- 所有深链在 GitHub Pages 环境刷新必须得到可恢复页面或明确静态 fallback，不能直接 404；具体 hash/history 方案在阶段 6 通过构建与真实 Pages 预览决定。
- 查询参数无效时安全忽略并显示默认视图；不崩溃、不发起高费用动作。
- 浏览器前进/后退恢复筛选、页签和滚动，不重放写操作。
- capability、秘密、完整输入、错误详情和个人数据禁止进入 URL、referrer 或分析事件。

## 8. 本地存储与离线

- IndexedDB 不可用、配额不足、版本迁移失败、隐私模式限制分别有可复现场景。
- 写失败时内存草稿仍留在当前页，并提供复制/导出安全路径；不显示“已保存”。
- Service Worker/PWA 不属于 v0.1 已批准范围；离线能力来自静态资源与本机 fixture，不新增离线缓存架构。
- 恢复联网不自动重放 AI、批准、导出、删除或其他可能产生费用/副作用的动作。

## 9. 资产清单与许可门

每个图片、图标、音频、字体资产记录：文件、用途、来源/生成方式、作者/机构、许可、修改、是否史料、替代文本、派生尺寸、体积和复核人。缺一项不得进入公开构建。

当前 AI 艺术方向、SVG 与 PNG 渲染稿都是设计证据而非发布资产；`dunhuang-hero-art-direction-v1.png` 不是史料。一次四帧故事板探索因出现疑似伪文字且定向修图网络失败，没有复制进项目或作为验证证据。当前没有批准音频、3D 运行时、网络字体或新图标依赖。

若阶段 6 技术原型发现现有依赖不能满足混合 3D，必须先比较平台原生能力与最小候选运行时的包体、维护、许可证、浏览器覆盖和退出成本，提交用户批准后才能安装。设计认可混合 3D 体验，不自动批准任何依赖。

## 10. 阶段 6 验证矩阵

阶段 6 分两道门记录证据：

1. **技术原型门**：各浏览器核心流程、UI 首次可用、3D 运行时/媒体体积、首个稳定增强帧、帧率/卡顿/内存、上下文丢失、四级降级、视差与镜头收束、首次/再次访问、重看、慢网/离线、自动播放允许/阻止、开关记忆、后台暂停和 reduced-motion。
2. **最终视觉验收门**：最终人物/洞窟/灯光/声音资产、临时资产清零、动画画风、暗转明转场、桌面/手机同一视觉身份以及全部许可记录。

同时继续验证长列表、深链刷新、IndexedDB 失败和 320px/200%/400% 缩放。未达到预算时先降级 3D、艺术层和图形增强，不削减来源、许可、批准或阻断信息；技术原型通过不代表最终视觉完成。
