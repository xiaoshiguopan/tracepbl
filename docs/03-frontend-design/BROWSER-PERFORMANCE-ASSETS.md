# 浏览器、性能、动效与资产基线

> 版本：0.1
> 日期：2026-08-31
> 状态：阶段 5 已批准归档
> 边界：前端可观察目标；具体构建配置在阶段 6 验证

## 1. 目标浏览器

以公开 Pages Demo 的访问目标为准：当前稳定版及前两个主要版本的 Chrome、Edge、Firefox、Safari；iOS Safari 与 Android Chrome 的常见稳定版本进行核心查看/轻编辑抽查。Internet Explorer 不支持。实际最低版本需在阶段 6 依据 Vite 输出、依赖兼容和浏览器实测冻结。

浏览器不支持 IndexedDB、自动播放、View Transition、容器查询或某种图像格式时必须渐进降级；核心闭环不能依赖实验性 API。

## 2. 首屏与交互预算

| 指标 | 设计预算 | 失败时优先动作 |
|---|---:|---|
| P00 首屏 HTML/真实文字可见 | 不等待影片解码 | 先显示明亮蓝色安全底与文字 |
| 首次主操作可用 | 首帧/脚本初始化后立即；不等待 7.5 秒影片 | 关闭装饰动画初始化 |
| P00 终帧后备图 | 当前 172,306 B；移动目标 ≤ 220 KB | 更强压缩或纯色安全底替代 |
| 首屏关键字体 | 0 个阻塞网络字体 | 使用系统字体栈 |
| 初始 JS（gzip，目标） | ≤ 180 KB | 路由分包、删除非必要可视化/动效代码 |
| P00 额外实时运行时代码 | 0 B；不添加 Three、Canvas 摄影机或视差运行时 | 使用原生影片与静态终帧 |
| P00 完整增强媒体总传输 | 当前批准成片 10,184,415 B；只在桌面且未减少动态时加载 | 后续只有重新通过视觉验收才可降码率 |
| P00 移动轻量媒体总传输 | 当前 172,306 B | 使用同片终帧 WebP，不下载 MP4 |
| 3D 首个稳定增强帧 | 参考桌面网络/设备目标 ≤ 2.5s；期间 UI 已可用 | 超时不再升级，保持当前安全层级 |
| 单路由追加 JS（gzip，目标） | 常规 ≤ 80 KB；关系图按需加载 | 列表为默认，图形视图延迟加载或关闭 |
| 布局偏移 | 不因图片、骨架、字体出现明显跳动 | 固定媒体比例、系统字体、稳定骨架 |
| 长任务反馈 | 2 秒内状态；30 秒提供取消 | 本地占位不冒充进度 |

预算是进入编码阶段的门槛目标，不是当前实测结果。最终以构建分析与真实浏览器记录为准。

## 3. 图像策略

- AI 艺术图与真实史料图分目录、分组件、分标签；艺术图文件名含 `art-direction`/`illustration`，史料图含来源 ID 和权利记录。
- P00 使用同片终帧 WebP 作为窄屏、减少动态和失败后备；不在 CSS 中嵌入超大 base64，也不保留旧主题 JPEG/PNG。
- 预渲染影片、响应式静态海报和 UI 分开打包；浏览器先取得 UI 与匹配尺寸海报，再按媒体能力加载影片。
- P00 预渲染片段必须提供桌面 MP4、同片终帧 WebP 和明确尺寸；移动、低带宽与减少动态默认使用终帧，不请求陀螺仪权限。
- 首屏背景设置固有宽高/比例，失败时显示 `narrative-void` + 可读标题，不显示破图图标。
- P01—P11 不预加载电影背景。真实史料图只有许可允许且进入视口时才加载，并有尺寸、alt、来源和权利说明。
- 不热链馆藏图片；不从搜索缩略图或生成图中提取“史料”。

## 4. 预渲染影片、动效性能与降级

- P00 按 `HYBRID-3D-OPENING-SPEC.md` 分为预渲染成片、同片终帧海报和真实 UI；不做实时角色、纸片、粒子、自由漫游、CSS 摄影机晃动或整屏高半径实时模糊。
- Canvas/媒体是独立装饰层；主内容独立于它，3D 初始化、上下文丢失或媒体解码异常不会挡住链接、滚动或焦点。
- P00 不随鼠标或触摸移动摄影机；指针反馈只允许作用于真实 UI，不能持续触发布局或 React 树重渲染。
- 页面不可见时暂停预渲染媒体；用户一次点击立即进入，不强制播完。
- 状态变化微动效 120—220ms；阻断/错误不摇晃；P00 是装饰性单次影片，7.5 秒后自动结束、不循环，用户可随时直接进入，减少动态时完全不创建视频元素。
- `prefers-reduced-motion` 直接使用最终静态帧；不只是把 7 秒缩成 1 秒。
- 自动播放失败、减少动态、数据节省或离线时显示静态海报；不能反复请求或用 CSS 模拟播放成功。

运行梯：预渲染影片 → 响应式静态海报 → 纯色安全首屏。媒体超时、解码失败、节省数据、reduced-motion 或离线均触发降级；任何一级都保留真实文字和进入动作。

## 5. 无声策略

项目不包含音频资产、音频请求、声音控件、自动播放逻辑或本机声音偏好。动效和转场不得依赖听觉提示传达状态。

## 6. 长内容与列表

- 候选 ≤ 50 条使用分页/分段渲染；超过 50 条先验证 `content-visibility` 或虚拟化必要性。虚拟化若破坏读屏、查找或焦点恢复，回退分页。
- 史料长文只渲染当前展开区；不把许可未知全文载入隐藏 DOM。
- 图形关系视图按需加载；等价列表始终先可用。图形达到 100 节点前必须重新评估，否则 v0.1 先限制可视概览，不改变数据真相。
- 搜索输入做合理防抖但保留即时清除；结果更新不抢焦点。

## 7. 路由、刷新与 Pages

- 所有深链在 GitHub Pages 环境刷新必须得到可恢复页面或明确静态 fallback，不能直接 404；具体 hash/history 方案在阶段 6 通过构建与真实 Pages 预览决定。
- 查询参数无效时安全忽略并显示默认视图；不崩溃、不发起高费用动作。
- 浏览器前进/后退恢复筛选、页签和滚动，不重放写操作。
- capability、秘密、完整输入、错误详情和个人数据禁止进入 URL、referrer 或分析事件。

## 8. 本地存储与离线

- IndexedDB 不可用、配额不足、版本迁移失败、隐私模式限制分别有可复现场景。
- 写失败时内存草稿仍留在当前页，并提供复制/导出安全路径；不显示“已保存”。
- Service Worker/PWA 不属于 v0.1 已批准范围；离线能力来自静态资源与本机 fixture，不新增离线缓存架构。
- 恢复联网不自动重放 AI、批准、导出、删除或其他可能产生费用/副作用的动作。

## 9. 资产清单与许可门

每个图片、图标和字体资产记录：文件、用途、来源/生成方式、作者/机构、许可、修改、是否史料、替代文本、派生尺寸、体积和复核人。缺一项不得进入公开构建。

阶段 5 的 AI 艺术图、SVG 与 PNG 只保留为历史设计证据，不是史料，也不进入运行时。现役页面只加载登记的 H3 V2 成片、同片终帧海报和本地字体；没有 Three 运行时、音频或网络字体依赖。

影片制作能力属于资产生产工具，不应变成浏览器生产依赖。若需要连接视频生成插件或安装制作工具，必须先获得用户对具体能力的授权；页面播放仍使用原生 `<video>`。

## 10. 阶段 6 验证矩阵

阶段 6 分两道门记录证据：

1. **技术原型门**：各浏览器核心流程、UI 首次可用、媒体体积、播放/结束/重播、卡顿、影片错误降级、首次/再次访问、慢网/离线、后台暂停和 reduced-motion。
2. **最终视觉验收门**：真实 7.5 秒成片、同片终帧海报、旧主题运行时资产清零、动画画风、匹配剪辑、桌面/手机同一视觉身份以及全部许可记录。

同时继续验证长列表、深链刷新、IndexedDB 失败和 320px/200%/400% 缩放。未达到预算时先降级 3D、艺术层和图形增强，不削减来源、许可、批准或阻断信息；技术原型通过不代表最终视觉完成。
