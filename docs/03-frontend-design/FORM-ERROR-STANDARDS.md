# 表单、反馈与错误展示

> 状态：阶段 5 已批准归档

## 1. 表单生命周期

`pristine → editing → client-invalid/ready → submitting → saved/authoritative-invalid/system-failed`。页面离开时若有未保存改动，先说明会丢失什么；自动保存页面仍显示最近保存结果，且关键确认必须显式完成。

## 2. 字段结构

顺序固定为：标签（含必填/可选）→ 目的说明 → 控件 → 示例/计数 → 错误。标签可点击；错误与控件关联。Placeholder 只展示格式示例并使用“…”；不得用 placeholder 替代标签。

选择“不确定”时不是跳过：展示它会影响史料难度、活动或评价的具体说明。输入不要求姓名、学校、班号或学生信息；疑似敏感内容触发安全提示并停止该部分处理。

## 3. 校验时机

- 输入中不对每个字符立即报错；离焦后校验已完整的字段。
- 提交时校验全部：顶部错误摘要宣布数量并链接字段，焦点落首个错误。
- 跨字段冲突（如课时与范围）显示在相关字段组和摘要中。
- 客户端校验只是体验；真实模式必须接受并显示 adapter/服务端权威校验结果。

## 4. 错误分类与展示

| 类别 | 展示位置 | 文案结构 | 主要动作 |
|---|---|---|---|
| `validation` | 字段 + 摘要 | 哪个值不合规则、如何修 | 修改字段 |
| `authorization` / unavailable | P12 安全页 | 此任务不可使用；不解释是否存在 | 返回起点 |
| `not-found` | P12 或对象区 | 对象不可使用；不泄露他人信息 | 返回安全列表 |
| `conflict` | 对象旁 + 影响摘要 | 内容已变化、你的编辑保留情况 | 比较并重新应用 |
| `rate-limit` | 页面 banner | 暂时无法继续、可重试时间（如可得） | 稍后重试/手工 |
| `external` | 单项/页面 | 哪个外部检查失败、哪些已保留 | 单项重试/手工补录 |
| `timeout` | 进度区 | 已等待多久、未完成、数据保留 | 取消/重试 |
| `cancelled` | 进度区 | 已取消哪些，哪些已完成 | 继续/返回 |
| `storage` | 全局 banner | 本机保存不可用及丢失风险 | 导出当前内容/继续临时会话 |
| `internal` | 页面错误边界 | 未完成、保留范围、追踪 ID | 重试/返回安全页 |

错误不道歉、不归咎用户、不写“未知错误，请稍后”；必须回答发生什么、保留什么、下一步。追踪 ID 可复制但不得包含 capability/秘密。

## 5. 异步与成功反馈

- 0—2 秒：按钮状态或行内“正在…”；2—30 秒：明确正在做什么；超过 30 秒：耗时、取消、手工替代。
- 不可测任务使用不确定进度，不虚构 73% 等百分比。分项任务显示完成/失败数量。
- Toast 仅提示已保存/已撤销等非关键反馈；阻断、批准、清除和导出结果必须在页面持久显示。
- 成功反馈使用动作同名：“情境已确认”“史料已批准”“文件已生成到你的设备”。

## 6. 重复、冲突与恢复

- 提交开始后按钮保持可见且显示 loading，阻止重复触发；不能在请求开始前就禁用导致无法提交。
- 相同内容重复确认/导出给一致结果；不会新建重复任务、重复收费或外发。
- 重新生成/替换先显示当前版与提案差异；默认保留教师编辑。
- 删除后如业务允许短暂撤销，明确截止；已主动清除/过期内容绝不提供假恢复。

## 7. 对话框与危险动作

仅用于整任务清除、会导致下游大面积待复核的上游变更、批量批准/退回和导出许可替代确认。标题直接说动作与对象；正文列影响与不可恢复部分；按钮分别是“取消”和具体危险动作。不得使用模糊“确定/取消”。

## 8. 示例文案

| 场景 | 推荐文案 |
|---|---|
| 来源超时 | “来源核验超时。你的卡片编辑已保留；可重试此来源或手工补录定位。” |
| 审计未知 | “2 项检查尚未完成，因此本次审计不能通过。” |
| 无权限 | “此任务不可使用。它可能已过期、已清除，或不属于当前访问。” |
| 上游改变 | “修改中心问题会让 3 张史料卡、2 个活动和量规进入待复核。当前内容不会立即删除。” |
| 导出成功 | “教学包已生成到你的设备。这是可试教候选，不代表已试教或允许公开再分发。” |
| Demo 离线 | “你当前离线。本机夹具和编辑仍可使用；外部来源链接暂时不可检查。” |
