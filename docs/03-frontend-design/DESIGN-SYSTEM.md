# 设计系统

> 名称：历史苏醒 / 证据工作台（History Awakens / Evidence Desk）
> 状态：阶段 5 已批准归档
> 目标气质：史诗、沉浸、厚重而不压迫阅读；不是聊天机器人、仿古网页、旅游海报或“AI 炫技台”

## 1. 视觉论点与签名元素

界面采用两幕结构。P00 第一印象是“千年历史在证据中苏醒”；进入任务后的第一印象是“我正在审阅一条可追踪的证据链”。完整视觉论点、敦煌叙事、AI 艺术边界、非阻塞时序、音频和代表页见 `VISUAL-DIRECTION.md`。

大胆度只花在两个彼此分工的元素上：品牌层的**混合 3D 证据光路**通过王圆箓提灯、洞窟纵深与一次残卷转场，把宏大叙事收束为可进入的工作台；工作流层的**证据脉络带**把问题、史料、主张、活动、量规、审计与批准连接起来。前者是可关闭/降级的装饰性导演镜头，后者编码真实状态。P00 只允许数量受控的尘埃/纸页和微视差，不扩散为全站 3D、鼠标追光或装饰粒子系统。

刻意避免暖奶油+高反差衬线、黑底荧光 AI、密集报纸分栏、满屏土黄羊皮纸和大红金国风海报。P00 使用近黑石窟与矿物色，P01—P11 回到冷淡石色工作台；朱砂只标阻断/危险，不作大面积品牌装饰。

## 2. 颜色令牌

暗场只属于 P00；工作台令牌供 P01—P12 使用。完整 token 表以 `VISUAL-DIRECTION.md` 第 5 节为准。

| Token | Hex | 用途 | 注意 |
|---|---|---|---|
| `narrative-void` | `#080D0F` | P00 暗场 | 不能扩散到长时工作页 |
| `mineral-blue` | `#294E59` | 暗场矿物冷光 | 不单独表示状态 |
| `lamp-gold` | `#C5A46A` | 灯光、时间坐标 | 不用于小号长正文 |
| `desk-canvas` | `#EEF1EF` | 工作台背景 | 冷淡石色，不模拟旧纸 |
| `desk-surface` | `#FBFCFA` | 卡片、表单 | 与背景有边界 |
| `desk-ink` | `#18211F` | 主文本 | 正文首选 |
| `desk-muted` | `#52605C` | 次要说明 | 仍需满足正文对比度 |
| `desk-line` | `#C6CFCA` | 分隔、输入边框 | 控件边界需实测 3:1 |
| `action-blue` | `#245B68` | 主操作、当前步骤、链接 | 不单独表示状态 |
| `verified-green` | `#276554` | 已核验/完成 | 同时配文字和图标 |
| `review-ochre` | `#7B5A18` | 待复核、需确认 | 不等同错误 |
| `blocker-red` | `#9E3F45` | 阻断、危险删除 | 不用于普通品牌装饰 |
| `focus-violet` | `#654FD1` | 键盘焦点 | 与页面状态色分开 |

状态浅底由上述颜色与白色混合形成，编码阶段以实际对比度检查确认具体值；不得靠降低不透明度得到不可读文本。成功、警告、错误均为“图标 + 标题 + 文本 + 可选边框”，颜色不是唯一通道。

## 3. 字体与排版

不加载阻塞首屏的大型网络字体。衬线标题/史料与现代无衬线 UI 的组合已经得到用户确认：

- 界面/正文：`system-ui, "Microsoft YaHei", "PingFang SC", "Noto Sans CJK SC", sans-serif`。
- 展示标题/史料原文/长引：`"Songti SC", "STSong", "Noto Serif CJK SC", SimSun, serif`；不使用毛笔字或假碑刻字体。
- 数据/ID：系统等宽栈；只用于定位号、追踪 ID、版本，不用于长正文。

| 层级 | 流式范围 | 行高 | 用途 |
|---|---|---:|---|
| Display | 44—72px | 1.15 | P00 桌面标题；Compact 为 36—46px |
| H1 | 28—36px | 1.2 | 页面标题 |
| H2 | 22—28px | 1.3 | 页面大区 |
| H3 | 18—22px | 1.4 | 卡片/分组标题 |
| Body | 16—18px | 1.7 | 中文正文与表单 |
| Small | 14—15px | 1.6 | 元数据、帮助；不得承载唯一关键状态 |

正文行宽 35—42 个中文字符；史料原文可到 46 字。标题使用 `text-wrap: balance`，正文长 URL/标识符允许断行。数字比较使用等宽数字。

## 4. 间距、形状与层级

- 4px 基准：`space-1=4`、`2=8`、`3=12`、`4=16`、`5=24`、`6=32`、`7=48`、`8=64`。
- 页面水平留白流式 16—40px；内容最大宽 1440px；阅读列最大 760px。
- 圆角：输入/小按钮 6px，卡片 10px，对话框 12px；状态标签可用胶囊，但普通按钮不全面胶囊化。
- 阴影只用于浮层与拖离文档流的元素；普通卡片以背景和边框分层。
- 层级固定：页面 0、sticky 导航 10、抽屉 30、遮罩 40、对话框 50、toast 60；tooltip 不承载唯一信息。

## 5. 核心组件规格

### 5.1 按钮与链接

- 主按钮每个区域最多一个，使用明确动词：“确认中心问题”“运行设计审计”“生成本地教学包”。
- 次按钮用于安全替代；危险按钮独立分区，默认不与主按钮相邻。
- 导航使用链接，动作使用按钮；图标按钮必须有可访问名称和 tooltip（tooltip 不是名称的替代）。
- 状态：default、hover、active、focus-visible、disabled、loading、error aftermath。Loading 文案使用中文省略号“…”并保留按钮宽度。

### 5.2 输入与表单

- 持久标签在控件上方；说明在标签下方；错误在控件后并用 `aria-describedby` 关联。
- 必填用文字“必填”而非仅星号；“暂不确定”是明确选项并说明影响。
- 复选框/单选的标签与控件共享至少 44×44px 推荐触控区域。
- 自动保存不替代显式确认；未保存、已保存、保存失败状态需可见。

### 5.3 卡片、列表与表格

- 候选/史料卡固定显示名称、来源、类型、核验、许可和纳入状态。
- 表格仅用于可比较结构；窄屏改为带字段名的卡片/定义列表，不删除字段。
- 超过 50 条候选时编码阶段评估虚拟化或 `content-visibility`；分页/筛选仍在 URL。
- 空字符串、超长标题、长 URL、古文和特殊字符均有换行策略。

### 5.4 状态、提示与对话框

- 行内状态用于对象结果；banner 用于全页阻断/离线/待复核；toast 只用于可忽略的短反馈。
- toast 不能承载唯一错误或批准状态；成功消息 `aria-live="polite"`，紧急安全错误在上下文中持久显示。
- 对话框只用于必须中断的确认/编辑；焦点进入、圈定、Esc 退出并回到触发器。危险对话框初始焦点放在“取消”。

### 5.5 证据脉络带

- 节点包含序号、步骤名、状态词、数量；连接线只表达顺序，不表达真伪。
- 桌面为左侧 rail；窄屏为摘要按钮 + 全屏步骤清单。
- 当前节点有文字“当前”；待复核、阻断不能只靠色点。
- 点击未满足步骤给出原因和链接，不静默无响应。

### 5.6 主张—证据视图

- 图形只作概览；列表是完整等价操作面。
- 关系类型使用文字：支持、质疑、补充语境、不能支持；线型/颜色只是增强。
- 节点可聚焦，读出名称、状态、关系数；所有增删改通过标准表单完成，不依赖拖拽。

## 6. 图标、插图、动效与声音

- 单一开源图标系统待前端编码阶段从已批准依赖或本地 SVG 中确认；本阶段不新增依赖。
- 使用线性图标并配文字；不以 emoji 表示核验、许可、危险或批准。
- P00 可使用明确标注的 AI 艺术化演绎；真实史料影像只能在许可核验后进入独立证据组件。生成图内不得出现可被误认成史料的文字。
- P00 允许 5—7 秒非阻塞混合 3D 编排；主内容从第一帧可用。导演式镜头、微视差、实时层与残卷转场见 `HYBRID-3D-OPENING-SPEC.md`，不能把“只动 transform/opacity”的普通 UI 规则错误套到 3D 渲染内部。其余状态动效 120—220ms，只动 `transform`/`opacity`，不得 `transition: all`。
- `prefers-reduced-motion` 直接显示同构图最终静态帧；Canvas/媒体不得进入焦点顺序、移动真实 UI 或遮挡焦点。
- 默认极轻环境声的许可、自动播放降级、显式关闭、本机偏好和后台暂停规则见 `VISUAL-DIRECTION.md` 与 `BROWSER-PERFORMANCE-ASSETS.md`。声音不是信息通道。

## 7. 文案规范

- 从教师视角命名：“保存情境”“退回核验”“查看受影响内容”，不用“提交 payload”“调用 Agent”。
- 错误结构：发生什么 + 保留什么 + 下一步。例如：“来源核验超时。你的卡片编辑已保留；可重试此来源或手工补录定位。”
- 成功动词前后一致：按钮“批准史料”，反馈“史料已批准”。
- 不使用“专家认证”“确保学习效果”“绝对可信”“自动查证无误”。
- Demo 始终称“作品集演示模式”；“可试教候选”不得缩写为“已完成教案”。

## 8. 设计自我批评与取舍

证据脉络带若同时承载太多数字会成为新的噪声，因此每节点最多显示一个最高优先级数量（阻断优先，其次待复核）；其余进入步骤详情。定位刻度只出现在来源/引文区域，不铺满全站。衬线字体只用于展示标题和明确史料，避免把产品做成泛化“历史报纸”。敦煌暗场和 3D 不延伸到工作台；如果 3D、动画、图像或声音影响首次操作、阅读、焦点、性能或用户舒适度，按完整→轻量→静态→纯色优先降级艺术层。
