# 信息架构、导航、URL 与页面清单

> 状态：阶段 5 已批准归档
> 用户：当前匿名教师；v0.1 无账号、管理员、团队或学生端

## 1. 信息架构结论

史证工坊只有一条产品主链：

```text
演示说明
└─ 当前任务
   ├─ 教学情境
   ├─ 探究问题
   ├─ 候选史料
   │  └─ 史料价值卡
   ├─ 主张—证据
   ├─ 活动与支架
   ├─ 评价量规
   ├─ 设计审计
   ├─ 教师审阅与批准
   ├─ 导出
   └─ 本机数据与清除
```

一级对象是“当前任务”，不是文件夹、聊天或 Agent。教师看到任务、证据、决定与影响，不看到内部模型、RAG 或多 Agent 结构。

## 2. 导航模型

### 2.1 全局导航

- 品牌入口“史证工坊”返回演示起点；返回前如有未保存编辑，先提示影响。
- 固定“作品集演示模式”标签，展开后说明：教学情境和交互状态是合成数据，史料元数据来自官方权威公开来源；数据只在当前浏览器，未连接在线 AI/数据库，不要输入真实学生或敏感数据。
- 当前任务菜单仅含“任务说明”“本机数据与清除”“新建演示任务”；没有账号、分享、管理员或跨任务列表。

### 2.2 任务导航

- 桌面：左侧“证据脉络带”按 1—9 展示主链，显示当前、已完成、待复核、阻断和未开始。
- 手机：顶部显示“第 n/9 步 + 当前名称”，点击打开全屏步骤清单；来源、批准和阻断摘要始终在正文首屏可达，不只藏在抽屉。
- 可返回任一已到达上游步骤；未满足前置条件的下游入口仍可聚焦，但激活后解释缺少条件和安全下一步，不用纯灰色制造死路。
- 上游变化后，在脉络带和相关页面同时标记“待复核”，并提供影响清单。

### 2.3 页面内导航

- 列表与筛选使用 URL 查询参数，刷新、复制链接和浏览器前进/后退后仍保持视图。
- 详情页使用真实链接；桌面可在同页右侧显示详情，但 URL 仍切换到详情地址。
- 页签只切换同一对象的视图；跨对象或跨步骤使用链接，不用页签伪装导航。
- 每页有跳至主内容链接；标题锚点留出 sticky header 的滚动边距。

## 3. URL 规范

以下只定义浏览器导航，不是后端 API。`:taskId` 和 `:sourceId` 是路由定位符，不是授权；完整模式必须由后续服务端重新校验 capability、资源归属和动作权限。

| ID | URL | 页面/职责 | 可深链状态 |
|---|---|---|---|
| P00 | `/demo` | 非阻塞敦煌混合 3D 首屏、四级降级、艺术/史料边界、数据说明、开始或继续本机任务 | `?scenario=` 仅开发/测试选择，公开构建不暴露工程开关；体验层级和重看不写 URL |
| P01 | `/tasks/:taskId/context` | 采集、校验和确认教学情境 | 无 |
| P02 | `/tasks/:taskId/question` | 诊断输入类型、比较并确认中心问题 | `?proposal=` |
| P03 | `/tasks/:taskId/sources` | 候选发现/输入、筛选、纳入与排除 | `?status=&type=&rights=&q=&page=` |
| P04 | `/tasks/:taskId/sources/:sourceId` | 核验出处、定位、加工、价值与局限 | `?section=provenance|excerpt|processing|value` |
| P05 | `/tasks/:taskId/evidence-map` | 编辑主张与支持/质疑/语境/不能支持关系 | `?claim=&view=map|list` |
| P06 | `/tasks/:taskId/lesson` | 活动、时长、证据产物与分层支架 | `?activity=` |
| P07 | `/tasks/:taskId/rubric` | 编辑证据对齐量规并看活动映射 | `?dimension=` |
| P08 | `/tasks/:taskId/audit` | 运行/重跑审计、定位阻断与确认项 | `?severity=&category=` |
| P09 | `/tasks/:taskId/review` | 汇总教师逐项审阅、修改和批准 | `?section=&status=` |
| P10 | `/tasks/:taskId/export` | 安全预览、许可替代、生成和下载 | `?format=docx|pdf`；格式可用性待编码验证 |
| P11 | `/tasks/:taskId/data` | 本机保存说明、导出备份提示、清除单项/整任务 | 无 |
| P12 | `/task-unavailable` | 过期、已删除、无权限或不存在的统一安全结果 | `?reason=expired|cleared|unavailable`，不带对象细节 |

规范：小写短横线；步骤 URL 使用稳定领域词；查询参数可重建视图但不保存秘密、capability、完整输入或个人数据；未知参数安全忽略；Pages 使用 history fallback 或构建期兼容方案在前端编码阶段验证，不在本阶段决定服务器配置。

## 4. 页面清单与完成条件

| 页面 | 对应需求 | 主任务 | 完成条件 | 主要阻断 |
|---|---|---|---|---|
| P00 演示起点 | MUST-010、NFR-010 | 理解边界并开始 | 确认演示与数据说明 | 未确认禁止数据提示 |
| P01 教学情境 | MUST-001 | 形成任务简报 | 必填/冲突解决并教师确认 | 课时无效、范围冲突、疑似敏感输入 |
| P02 探究问题 | MUST-002 | 收束中心问题 | 类型、问题、预期证据产物确认 | 空/超长/预设答案/超课时 |
| P03 候选史料 | MUST-003 | 建立候选集合 | 至少有可继续核验的候选或教师明确选择手工路径 | 无候选、材料不支持、权利或敏感风险 |
| P04 史料价值卡 | MUST-004 | 完成单份史料核验与加工记录 | 必需字段、定位、价值/局限和状态明确 | 引文错配、关键元数据缺失、许可不明 |
| P05 主张—证据 | MUST-005 | 建立可审计关系 | 每个核心主张有明确关系或缺口标记 | 零史料、同源、未连接、冲突未处理 |
| P06 活动与支架 | MUST-006 | 形成证据依赖活动 | 时长内、绑定史料、产物和困难 | 不用证据也能完成、总时长超限 |
| P07 量规 | MUST-007 | 形成行为锚定量规 | 证据四维度或有理由的适用取舍 | 缺上游产物、空泛等级、删除全部证据维度 |
| P08 审计 | MUST-008 | 检查全链路门禁 | 无阻断；需确认项有教师理由 | 未知/失败、来源/许可/设计错位 |
| P09 审阅与批准 | MUST-009 | 教师逐项控制 | 拟导出对象均批准且无待复核 | 任一未批准/阻断/受影响项 |
| P10 导出 | MUST-009 | 生成本地可试教候选 | 预览一致且文件生成成功 | 许可不允许复制、内容缺项、生成失败 |
| P11 本机数据 | MUST-010 | 理解/清除当前任务 | 清除有明确结果；重复清除一致 | 存储或清除失败 |
| P12 不可用 | MUST-010、NFR-003 | 安全返回起点 | 新建任务或返回演示说明 | 不泄露对象是否属于他人 |

## 5. 内容优先级

P00 例外采用“混合 3D 装饰层 + 独立真实文字层”，但演示边界、艺术化演绎和主动作从第一帧可用；完整/轻量/静态/纯色四级都保持同一信息架构。P01—P12 从上到下固定为：页面标题与完成条件 → 演示/任务状态 → 阻断或待复核摘要 → 当前主任务 → 证据/详情 → 次要帮助。来源状态、许可、教师批准和审计阻断永远是一级信息；帮助、技术追踪 ID 和高级详情可渐进展开。逐页布局、字段、交互和完整文案见 `PAGE-SPECIFICATIONS.md`。

## 6. 明确不设计

无登录/注册、任务库、收藏夹、团队分享、管理员后台、学生端、消息中心、计费页、模型选择器、Agent 运行图或跨任务搜索。P11 只管理当前浏览器/任务数据，不暗示云端账户能力。
