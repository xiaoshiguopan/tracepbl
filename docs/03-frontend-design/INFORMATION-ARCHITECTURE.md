# 信息架构、导航、URL 与页面清单

> 现役覆盖说明：2026-09-03 深度优化后的八步任务架构与本机任务抽屉见 `FRONTEND-DEEP-OPTIMIZATION-SPEC.md`。

> 状态：阶段 5 已批准归档
> 当前修订：2026-09-02 P09 以“装订清样 + 一次教师签发 + 同页打印”落地
> 用户：当前匿名教师；v0.1 无账号、管理员、团队或学生端

## 1. 信息架构结论

史证工坊只有一条产品主链：

```text
演示说明
└─ 当前任务
   ├─ 教学情境
   ├─ 探究问题
   ├─ 查找史料（发现、自动核验结果、直接阅读、推荐与选择）
   ├─ 主张—证据
   ├─ 活动与支架
   ├─ 评价量规
   ├─ 设计检查
   ├─ 最终确认与导出
   └─ 本机数据与清除
```

一级对象是“当前任务”，不是文件夹、聊天或 Agent。教师看到任务、证据、决定与影响，不看到内部模型、RAG 或多 Agent 结构。

## 2. 导航模型

### 2.1 全局导航

- 品牌入口“史证工坊”返回演示起点；返回前如有未保存编辑，先提示影响。
- 固定“作品集演示模式”标签，展开后说明：教学情境和交互状态是合成数据，史料元数据来自官方权威公开来源；数据只在当前浏览器，未连接在线 AI/数据库，不要输入真实学生或敏感数据。
- 当前任务菜单仅含“任务说明”“本机数据与清除”“新建演示任务”；没有账号、分享、管理员或跨任务列表。

### 2.2 任务导航

- 桌面：左侧“证据脉络带”优先显示当前与下一步，后续步骤渐进展开；已到达步骤才成为链接或按钮，未实现/未到达步骤只作路线说明，不制造假入口。
- 手机：主证据流程固定显示“第 n/8 步 + 下一步”；完整步骤清单按需展开，来源、确认和阻断摘要始终在正文首屏可达。
- 可返回任一已到达上游步骤；未满足前置条件的下游步骤以文字解释缺少条件和安全下一步，不用可点击但无去处的控件。
- 上游变化后，在脉络带和相关页面同时标记“待复核”，并提供影响清单。

### 2.3 页面内导航

- 列表与筛选使用 URL 查询参数，刷新、复制链接和浏览器前进/后退后仍保持视图。
- 史料的完整依据在 P03 内渐进展开；官方来源使用真实链接。P03 不依赖独立价值卡详情路由。
- 页签只切换同一对象的视图；跨对象或跨步骤使用链接，不用页签伪装导航。
- 每页有跳至主内容链接；标题锚点留出 sticky header 的滚动边距。

## 3. URL 规范

以下只定义浏览器导航，不是后端 API。`:taskId` 和 `:sourceId` 是路由定位符，不是授权；完整模式必须由后续服务端重新校验 capability、资源归属和动作权限。

| ID | URL | 页面/职责 | 可深链状态 |
|---|---|---|---|
| P00 | `/demo` | 非阻塞敦煌预渲染电影首屏、静态/纯色回退、艺术/史料边界、数据说明、开始或继续本机任务 | `?scenario=` 仅开发/测试选择，公开构建不暴露工程开关；媒体能力不写 URL |
| P01 | `/tasks/:taskId/context` | 采集、校验和确认教学情境 | 无 |
| P02 | `/tasks/:taskId/question` | 诊断输入类型、比较并确认中心问题 | `?proposal=` |
| P03 | `/tasks/:taskId/sources` | 轻量知识库优先发现、按需外部补充；呈现自动核验后的可读史料、推荐依据、选择/排除和教师材料元数据输入 | `?scope=&type=&function=&q=&page=&source=`；参数只重建视图，不代表真实检索或授权 |
| P04 | 无独立 URL | MUST-004 作为 P03 内部自动核验与证据记录能力；结果进入史料卡和后续审计 | 不适用；不得恢复为教师逐字段核验页 |
| P05 | `/tasks/:taskId/evidence-map` | 编辑主张与支持/质疑/语境/不能支持关系 | `?claim=&view=map|list` |
| P06 | `/tasks/:taskId/lesson` | 活动、时长、证据产物与分层支架 | `?activity=` |
| P07 | `/tasks/:taskId/rubric` | 编辑证据对齐量规并看活动映射 | `?dimension=` |
| P08 | `/tasks/:taskId/audit` | 直接呈现设计检查、定位阻断/未知/确认项并按影响重检 | `?severity=&category=`；当前 Demo 的 `?p08-state=` 仅用于开发验证 |
| P09 | `/tasks/:taskId/review` | 复用上游教师决定，以一次最终签发确认整包，并在同页完成权利替代预览、文件名和浏览器打印 | 开发 Demo 仅用 `?p09-state=` 验证状态；不建立第二套格式页 |
| P10 | 无独立 URL | 原导出能力并入 P09；不得恢复独立步骤或第二套确认状态 | 不适用 |
| P11 | 取消，不建立 URL | 用户明确决定不实现本机数据查看与清除页；不得用 P12 冒充清除能力 | 不适用 |
| P12 | `/task-unavailable` | 过期、已删除、无权限或不存在的统一安全结果 | `?reason=expired|cleared|unavailable`，不带对象细节 |

规范：小写短横线；步骤 URL 使用稳定领域词；查询参数可重建视图但不保存秘密、capability、完整输入或个人数据；未知参数安全忽略；Pages 使用 history fallback 或构建期兼容方案在前端编码阶段验证，不在本阶段决定服务器配置。

## 4. 页面清单与完成条件

| 页面 | 对应需求 | 主任务 | 完成条件 | 主要阻断 |
|---|---|---|---|---|
| P00 演示起点 | MUST-010、NFR-010 | 理解边界并开始 | 确认演示与数据说明 | 未确认禁止数据提示 |
| P01 教学情境 | MUST-001 | 确定本课最小边界 | 课程必填项合法并由教师一次确认 | 课时无效、学段/年级冲突、可见字段疑似敏感输入 |
| P02 探究问题 | MUST-002 | 收束中心问题 | 类型、问题、预期证据产物确认 | 空/超长/预设答案/超课时 |
| P03 查找史料 | MUST-003、MUST-004 | 直接阅读可用史料及推荐依据并建立本课史料组 | 至少选择满足当前任务门槛的史料，或教师明确返回调整问题/录入材料元数据 | 无可用史料、引文错配、关键元数据缺失、权利/敏感风险、自动核验未完成 |
| P05 主张—证据 | MUST-005 | 建立可审计关系 | 每个核心主张有明确关系或缺口标记 | 零史料、同源、未连接、冲突未处理 |
| P06 活动与支架 | MUST-006 | 形成证据依赖活动 | 时长内、绑定史料、产物和困难 | 不用证据也能完成、总时长超限 |
| P07 量规 | MUST-007 | 形成行为锚定量规 | 证据四维度或有理由的适用取舍 | 缺上游产物、空泛等级、删除全部证据维度 |
| P08 设计检查 | MUST-008 | 直接处理全链路异常 | 无阻断/未知；需确认项有合规教师理由 | 未知/失败、来源/许可/设计错位 |
| P09 最终确认与导出 | MUST-009 | 审阅装订清样、一次签发并在本机打印/另存为 PDF | 上游决定有效、权利替代可见、教师最终确认且打印入口可用 | 任一上游待复核/阻断、许可边界不明、内容缺项、文件名无效 |
| P10 导出能力 | MUST-009 | 并入 P09，不承担独立页面主任务 | 不适用 | 不得形成重复确认或失去 P09 安全状态 |
| P11 本机数据 | MUST-010 | 已取消，不承担页面主任务 | 不适用 | 应用内查看/清除本机任务数据能力明确缺失 |
| P12 不可用 | MUST-010、NFR-003 | 安全返回起点 | 新建任务或返回演示说明 | 不泄露对象是否属于他人 |

## 5. 内容优先级

P00 例外采用“预渲染电影装饰层 + 独立真实文字层”，但演示边界、艺术化演绎和主动作从第一帧可用；影片/静态/纯色各级都保持同一信息架构。P01—P12 从上到下固定为：页面标题与完成条件 → 演示/任务状态 → 阻断或待复核摘要 → 当前主任务 → 证据/详情 → 次要帮助。P04 仅保留内部能力编号，不再是页面。来源、权利、推荐依据、教师选择/批准和审计阻断永远是一级信息；帮助、技术追踪 ID 和高级依据可渐进展开。逐页布局、字段、交互和完整文案见 `PAGE-SPECIFICATIONS.md`。

## 6. 明确不设计

无登录/注册、任务库、收藏夹、团队分享、管理员后台、学生端、消息中心、计费页、模型选择器、Agent 运行图或跨任务搜索。P11 已由用户取消；当前版本不提供应用内本机任务数据查看或清除入口。
