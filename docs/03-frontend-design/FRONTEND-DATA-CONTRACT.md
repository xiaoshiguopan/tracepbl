# 前端数据需求契约

> 状态：阶段 5 已批准归档
> 地位：从页面行为反推的前端需求，不是数据库 Schema、ORM 模型或具体 HTTP API；阶段 7/9 必须验证，不能据此假定实现

## 1. 契约原则

- Demo adapter 与未来真实 adapter 向页面提供同样的视图数据、操作结果和错误语义。
- 页面只请求完成当前任务所需字段；不接收数据库行、厂商模型对象、内部日志或他人资源存在性。
- 所有结构带 `contractVersion`；未知破坏性版本安全失败。
- 时间为 ISO 8601/UTC 输入，界面用本地化格式显示并明确北京时间；金额带币种和估算/实际属性。
- ID 不透明；task ID 只定位，不授权。capability 不进入 URL、普通日志、fixture 或可复制错误。

## 2. 通用包络

| 结构 | 必需内容 | 页面用途 |
|---|---|---|
| `ViewResult<T>` | `data`、`contractVersion`、`loadedAt`、`freshness` | 区分新鲜、缓存、本机与待同步 |
| `CommandResult<T>` | `result`、`operationId`、`acceptedAt`、`idempotencyOutcome`、`impact` | 写入反馈、重复提交与影响传播 |
| `OperationStatus` | `queued/running/partial/succeeded/failed/cancelled`、已完成/总数（可得时）、耗时、可取消、分项结果 | 生成、核验、审计、导出 |
| `Problem` | 稳定 `code`、类别、安全中文消息、字段问题、可重试、追踪 ID、保留范围、建议动作 | 所有错误展示 |
| `ImpactSet` | 受影响对象的 ID、类型、当前/新状态、原因、建议链接 | 上游改变和重新生成 |

`Problem` 不得含堆栈、SQL、内部路径、第三方原始响应、密钥、capability、完整提示词或他人内容。

## 3. 枚举语义（前端所需）

| 名称 | 值 | 说明 |
|---|---|---|
| 核验 | `candidate/pending/verified/conditional/excluded` | 与 PRD 来源状态一致 |
| 批准 | `notReady/pending/approved/changesRequested/stale` | `stale` 表示上游变化后待复核 |
| 审计严重度 | `blocking/teacherConfirmation/suggestion/pass/unknown` | `unknown` 不能视为 pass |
| 关系 | `supports/challenges/contextualizes/cannotSupport` | 必须有文字理由 |
| 权利 | `verifiedReusable/restrictedMetadataOnly/unknown/notAllowed` | 决定导出替代，不等同核验 |
| 数据类别 | `synthetic/publicLicensed/publicUnknown/internalTemporary/prohibited` | 前端用于警示与阻断；真实判断需权威结果 |
| 运行模式 | `demo/complete` | 页面必须显著区分 |

`synthetic` 仅适用于教学情境、用户输入、活动、量规、错误和系统状态等非史料数据。史料对象不得使用 `synthetic`：其本体、出处、版本、馆藏号和引文必须来自官方权威公开来源；无法确认复制许可时使用 `publicUnknown` 或 `restrictedMetadataOnly`，只展示必要元数据和官方链接。

## 4. 页面读取需求

### P00 `DemoEntryView`

运行模式、夹具版本、本机存储可用性、是否有可继续的当前任务、数据边界文案版本、禁止输入类型、离线状态；另含艺术资产版本、`artisticInterpretation` 常驻说明、motion preference、是否看过序章、用户主动重看意图和一次点击转场状态。体验层级 `full3d/lightMotion/static/safeColor`、媒体就绪/失败和上下文丢失属于前端环境能力，不是服务端领域事实；不能把设备型号、指针轨迹或性能指纹写入契约。产品无音频字段。艺术字段不能提供历史事实或史料状态。不得返回其他本机/服务端任务列表。

### P01 `TeachingContextView`

任务最小摘要、学段/年级、教材/课次、分钟、可选课型、可选初步探究方向、客户端约束说明、权威冲突、确认状态、保存状态、上次安全版本和下游影响预览。当前教学情境摘要只由本地字段即时派生，不是独立生成物、检索结果、可信度结论或安全授权。史料用途/数量/组成属于 P03 的查找前条件；匿名学情属于 P06 的活动与支架输入。

### P02 `QuestionWorkspaceView`

已确认情境摘要、原始输入、输入类型及理由、一个或多个有限建议、建议差异、中心问题草稿、学生证据产物、约束/风险和当前确认版。

### P03 `CandidateSourceCollectionView`

当前问题摘要、候选总数/匹配数、分页信息、可用筛选定义、当前筛选、候选摘要、分项操作状态和添加材料能力说明。

每个候选摘要至少需要：ID、题名、来源机构/作者、类型、稳定定位/标识符（如有）、发现路径、访问日期、核验、权利、数据类别、是否已纳入/排除、失败/限制摘要。列表不需返回全文。

### P04 `SourceEvidenceCardView`

公共字段：题名、作者/制作者、年代、类型、来源机构/出版物、稳定链接/标识符、精确定位、访问日期、语言、权利、核验与依据；内容字段：可用摘录、删节、翻译/释义、教学加工、AI 加工的明确边界；判断字段：当前问题、价值、局限、可支持/不能支持主张；变更、教师批注、批准状态和影响。

类型补充字段遵循 PRD，但以“带标签的字段集合”提供给视图，不要求前端了解数据库列。

### P05 `ClaimEvidenceWorkspaceView`

中心问题、核心主张/子问题、史料摘要、关系列表、缺口/同源/冲突/过度概括提示、图形布局建议（非真相）、受影响活动/量规摘要。关系由主张 ID、史料 ID、关系类型、理由和复核状态组成。

### P06 `LessonDesignView`

情境/问题摘要、可用分钟、活动顺序、每项分钟、绑定史料、学生操作、证据产物、对应困难、支架、教师编辑标记、总时长、约束和影响。

### P07 `RubricDesignView`

活动与证据产物摘要、维度、至少三个等级及可观察行为锚点、活动映射、对齐状态、删除维度影响和教师编辑标记。不需要真实学生、作品、成绩或姓名。

### P08 `AuditWorkspaceView`

审计对象版本、运行状态、运行/复用时间、类别摘要、发现列表、严重度、对象链接、依据、修复建议、教师确认理由、是否仍有效、失败/未知项和是否允许进入审阅。

### P09 `TeacherReviewView`

按问题/史料/活动/支架/量规分组的审阅项、内容摘要、核验/权利/审计、当前批准、待复核原因、最后修改者类别（教师/系统建议，不含个人身份）、整体可交付性和阻断。

### P10 `ExportPreparationView`

教学包章节、每章状态、拟含史料及权利处理、元数据/链接替代、格式选项、版本/时间、文件名建议、预计生成方式/成本（如有）、生成状态和下载结果。下载引用应短期有效或本机对象，不暴露存储路径。

### P11 `TaskDataView`

运行模式、保存位置解释、最后活动、预计失效（可得时）、内容类别与数量、可清除单项、整任务影响、清除操作状态。不得显示他人任务或后台数据目录。

## 5. 前端所需动作（业务语义，不规定传输方式）

| 动作 | 输入最小化 | 成功结果 | 失败/重复要求 |
|---|---|---|---|
| 建立任务 | 演示边界确认、fixture 版本 | 当前任务定位与初始状态 | 重复只返回当前安全任务 |
| 保存/确认情境 | 最小表单值、基线版本、幂等键 | 情境确认、下一步定位、影响 | 冲突返回差异，不覆盖；不要求先生成摘要 |
| 诊断/确认问题 | 输入、情境版本、选择/编辑 | 建议或确认版、影响 | 超时可取消；旧版保留 |
| 获取/添加候选 | 问题版本、筛选或材料最小信息 | 分项候选状态 | 去重；单项失败不清空其他项 |
| 保存/核验史料卡 | 字段、基线版本、动作意图 | 权威核验/权利状态、影响 | 引文错配必须降级；批注保留 |
| 保存主张/关系 | 对象 ID、关系、理由、基线 | 新关系与缺口 | 重复返回已有关系 |
| 保存/生成活动 | 已确认输入、当前草稿、生成范围 | 提案/确认版、时长与影响 | 默认不覆盖教师编辑 |
| 保存/生成量规 | 活动/产物版本、当前草稿 | 提案/对齐结果 | 缺上游不输出空壳 |
| 运行/取消审计 | 对象版本、范围、幂等键 | 分项结果、阻断、未知 | 重复复用需显示时间；取消不假成功 |
| 批准/退回 | 对象版本、动作、理由（必要时） | 权威批准与可交付性 | 变更冲突需重审；前端不可自行放行 |
| 生成/取消导出 | 审阅版本、格式、许可处理、幂等键 | 状态与下载结果 | 重复一致；失败不生成损坏成功文件 |
| 清除单项/任务 | 精确目标、影响确认、幂等键 | 安全结果/终态 | 重复一致，不泄露归属 |

## 6. 列表、分页与筛选

- 候选列表默认按“阻断/待核验优先，其次相关顺序”展示，实际排序来源必须可解释。
- 页码或游标是实现待定；前端只要求 `items`、`hasMore/total`（至少其一）、稳定排序说明和可恢复视图位置。
- 筛选条件由 adapter 声明支持项；URL 使用稳定值。清除筛选后恢复全量数量。
- 超过 50 条时前端编码阶段验证分页/虚拟化；不预设数据库查询或索引。

## 7. 离线、缓存与并发需求

- Demo：IndexedDB 中保存版本化任务快照，迁移失败时不静默丢弃；提供导出/清除说明。
- 完整模式：页面需要区分 fresh/cached/pendingSync；离线编辑是否允许按动作逐项声明，批准/核验/审计/删除不得假成功。
- 所有可编辑对象需要基线版本或等价冲突证据；冲突返回当前权威版、教师草稿和安全下一步。
- 恢复联网不会自动重放可能产生费用、批准、导出或删除的动作。

## 8. 后续设计验证问题

阶段 7 必须验证这些数据关系和生命周期能否安全持久化，但不得把页面等同于表。阶段 9 必须决定传输方式、请求限制、鉴权、错误码、SSE/轮询和幂等实现；若改变前端可观察行为，退回阶段 5。当前明确未决定：HTTP 路径/方法、数据库字段类型/表、游标格式、文件上传限额具体数字、导出格式库、在线事件协议。

字段命名、adapter 能力、fixture 根包、场景注入和具体 JSON 形状由 `VIEW-MODEL-FIXTURE-SPEC.md` 冻结；逐页字段与文案以 `PAGE-SPECIFICATIONS.md` 为准。三者冲突时先修订设计，不在编码中任选一份。
