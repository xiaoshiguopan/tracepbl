# 前端数据需求契约

> 现役覆盖说明：本机任务索引、匿名学情、问题规模/子问题、12 条史料池、证据复用、活动支架及导出边界见 `FRONTEND-DEEP-OPTIMIZATION-SPEC.md`。

> 状态：阶段 5 与阶段 7 数据生命周期同步均已批准归档
> 当前修订：2026-09-03 明确 Pages/完整本地模式、任务菜单删除和 workspace 边界
> 地位：从页面行为反推的前端需求，不是数据库 Schema、ORM 模型或具体 HTTP API；阶段 7/9 必须验证，不能据此假定实现

## 1. 契约原则

- Demo adapter 与未来真实 adapter 向页面提供同样的视图数据、操作结果和错误语义。
- 页面只请求完成当前任务所需字段；不接收数据库行、厂商模型对象、内部日志或他人资源存在性。
- 所有结构带 `contractVersion`；未知破坏性版本安全失败。
- 时间为 ISO 8601/UTC 输入，界面用本地化格式显示并明确北京时间；金额带币种和估算/实际属性。
- ID 不透明；task ID 只定位，不授权。任何访问凭据或内部 workspace 标识不进入 URL、普通日志、fixture 或可复制错误。

## 2. 通用包络

| 结构 | 必需内容 | 页面用途 |
|---|---|---|
| `ViewResult<T>` | `data`、`contractVersion`、`loadedAt`、`freshness` | 区分新鲜、缓存、本机与待同步 |
| `CommandResult<T>` | `result`、`operationId`、`acceptedAt`、`idempotencyOutcome`、`impact` | 写入反馈、重复提交与影响传播 |
| `OperationStatus` | `queued/running/partial/succeeded/failed/cancelled`、已完成/总数（可得时）、耗时、可取消、分项结果 | 生成、核验、审计、导出 |
| `Problem` | 稳定 `code`、类别、安全中文消息、字段问题、可重试、追踪 ID、保留范围、建议动作 | 所有错误展示 |
| `ImpactSet` | 受影响对象的 ID、类型、当前/新状态、原因、建议链接 | 上游改变和重新生成 |

`Problem` 不得含堆栈、SQL、内部路径、第三方原始响应、密钥、访问凭据、内部 workspace 标识、完整提示词或他人内容。

## 3. 枚举语义（前端所需）

| 名称 | 值 | 说明 |
|---|---|---|
| 核验 | `candidate/pending/verified/conditional/excluded` | 与 PRD 来源状态一致 |
| 批准 | `notReady/pending/approved/changesRequested/stale` | `stale` 表示上游变化后待复核 |
| 审计严重度 | `blocking/teacherConfirmation/suggestion/pass/unknown` | `unknown` 不能视为 pass |
| 关系 | `background/supports/turningPoint/consequence/challengesOrLimits` | 对应现役“背景条件/支持原因/关键转折/后续影响/质疑或限制”，必须有文字理由 |
| 权利 | `verifiedReusable/restrictedMetadataOnly/unknown/notAllowed` | 决定导出替代，不等同核验 |
| 数据类别 | `synthetic/publicLicensed/publicUnknown/internalTemporary/prohibited` | 前端用于警示与阻断；真实判断需权威结果 |
| 运行模式 | `demo/complete` | 页面必须显著区分 |

`synthetic` 仅适用于教学情境、用户输入、活动、量规、错误和系统状态等非史料数据。史料对象不得使用 `synthetic`：其本体、出处、版本、馆藏号和引文必须来自官方权威公开来源；无法确认复制许可时使用 `publicUnknown` 或 `restrictedMetadataOnly`，只展示必要元数据和官方链接。

## 4. 页面读取需求

### P00 `DemoEntryView`

运行模式、夹具版本、本机存储可用性、可继续任务与当前浏览器/本地 workspace 自有任务索引、数据边界文案版本、禁止输入类型、离线状态；另含艺术资产版本、`artisticInterpretation` 常驻说明、motion preference、是否看过序章、用户主动重看意图和一次点击转场状态。体验层级 `full3d/lightMotion/static/safeColor`、媒体就绪/失败和上下文丢失属于前端环境能力，不是服务端领域事实；不能把设备型号、指针轨迹或性能指纹写入契约。产品无音频字段。艺术字段不能提供历史事实或史料状态。不得返回另一 workspace 或他人任务。

### P01 `TeachingContextView`

任务最小摘要、学段/年级、教材/课次、分钟、可选课型、可选初步探究方向、客户端约束说明、权威冲突、确认状态、保存状态、上次安全版本和下游影响预览。当前教学情境摘要只由本地字段即时派生，不是独立生成物、检索结果、可信度结论或安全授权。史料用途/数量/组成属于 P03 的查找前条件；匿名学情属于 P06 的活动与支架输入。

### P02 `QuestionWorkspaceView`

已确认情境摘要、原始输入、输入类型及理由、一个或多个有限建议、建议差异、中心问题草稿、学生证据产物、约束/风险和当前确认版。

### P03 `CandidateSourceCollectionView`

当前问题摘要、自动整理的史料组合条件、发现范围（已登记知识库/外部补充）、候选总数/推荐数/匹配数、稳定排序说明、分页信息、可用筛选定义、当前筛选、候选摘要、分项发现/核验状态、选择进度和添加材料能力说明。

每个可用候选至少需要：ID、题名、来源机构/作者、年代、类型、稳定定位/标识符、发现路径、访问日期、可合法展示的必要摘录或预览、内容层级标签、可用/有条件可用状态、权利、数据类别、推荐层级与自然语言理由、可帮助判断、不能单独证明、是否已选择/排除和限制摘要。页面不需要不必要的版权全文。

### P04 `SourceEvidenceRecordView`（P03 内部能力，无独立页面）

公共字段：题名、作者/制作者、年代、类型、来源机构/出版物、稳定链接/标识符、精确定位、访问日期、语言、权利、自动核验状态与依据；内容字段：可用摘录、删节、翻译/释义、教学加工、AI 加工的明确边界；判断字段：当前问题、推荐理由、价值、局限、可帮助判断/不能单独证明；变更、教师选择/批注、批准状态和影响。该结构嵌入 P03 史料卡与完整依据，不要求独立路由。

类型补充字段遵循 PRD，但以“带标签的字段集合”提供给视图，不要求前端了解数据库列。

### P05 `ClaimEvidenceWorkspaceView`

中心问题、核心主张/子问题、史料摘要、关系列表、缺口/同源/冲突/过度概括提示、图形布局建议（非真相）、受影响活动/量规摘要。关系由主张 ID、史料 ID、关系类型、理由和复核状态组成。

### P06 `LessonDesignView`

情境/问题摘要、可用分钟、活动顺序、每项分钟、绑定史料、学生操作、证据产物、对应困难、支架、教师编辑标记、总时长、约束和影响。

### P07 `RubricDesignView`

活动与证据产物摘要、维度、至少三个等级及可观察行为锚点、活动映射、对齐状态、删除维度影响和教师编辑标记。不需要真实学生、作品、成绩或姓名。

### P08 `AuditWorkspaceView`

检查对象版本、输入链摘要、结果来源/复用状态、类别快照、通过项、发现列表、严重度、对象链接、依据、影响、首选处理、教师确认理由、失效类别、失败/未知项、完成状态和是否允许进入最终确认与导出。Demo adapter 提供确定性预生成结果；未来真实 adapter 才可提供权威检查时间与运行状态。客户端不得把 fixture、字段齐全或绿色样式升级为安全授权。

### P09 `FinalReviewExportView`

按问题/史料/活动/支架/量规分组的内容摘要、核验/权利/检查结果、上游教师决定、待复核原因、整体可交付性和阻断；同一视图包含教学包章节、拟含史料及权利处理、必要短引/元数据/链接替代、一次最终签发、签发快照、文件名和浏览器打印状态。首版不返回格式列表、下载 URL 或本机路径；页面只能确认已调用浏览器打印窗口，不能推断用户已保存文件。

### P10 导出能力（无独立页面）

原 `ExportPreparationView` 并入 P09 `FinalReviewExportView`；不得建立独立 route、页面 store 或第二套批准状态。

### P11 `TaskDataView`

用户已明确取消 P11，当前版本不实现独立 `TaskDataView`、回收站或对应页面状态。已实现的全局任务菜单可以列出、继续、复制和删除本机自有任务；删除反馈留在菜单/任务壳中，不恢复 P11。P12 不读取任务对象，也不能把安全返回文案解释为删除已成功。

### P12 `TaskUnavailableView`

不接收任务对象、标题、所有者、存在性或具体失败原因。仅提供固定公共说明，以及“新建演示任务”和“返回演示说明”两个安全导航动作；未知查询参数不改变页面内容。

## 5. 前端所需动作（业务语义，不规定传输方式）

| 动作 | 输入最小化 | 成功结果 | 失败/重复要求 |
|---|---|---|---|
| 建立任务 | 演示边界确认、fixture 版本 | 当前任务定位与初始状态 | 重复只返回当前安全任务 |
| 保存/确认情境 | 最小表单值、基线版本、幂等键 | 情境确认、下一步定位、影响 | 冲突返回差异，不覆盖；不要求先生成摘要 |
| 诊断/确认问题 | 输入、情境版本、选择/编辑 | 建议或确认版、影响 | 超时可取消；旧版保留 |
| 发现/补充史料 | 问题版本、发现范围、筛选或材料最小信息 | 知识库优先、按需外部补充的分项状态 | 去重；单项失败不清空其他项；Demo 不伪造真实检索 |
| 选择/排除史料 | 史料 ID、基线版本、动作意图、可选原因 | 史料组、覆盖缺口与影响 | 重复动作一致；保留教师决定，不自动替换 |
| 自动核验史料 | 史料与问题版本、核验范围 | 权威核验/权利/推荐依据、影响 | 引文错配或未知必须移出可用区；教师选择和批注保留 |
| 保存主张/关系 | 对象 ID、关系、理由、基线 | 新关系与缺口 | 重复返回已有关系 |
| 保存/生成活动 | 已确认输入、当前草稿、生成范围 | 提案/确认版、时长与影响 | 默认不覆盖教师编辑 |
| 保存/生成量规 | 活动/产物版本、当前草稿 | 提案/对齐结果 | 缺上游不输出空壳 |
| 完成/重新检查 | 对象与类别快照、教师确认理由、受影响范围、幂等键 | 分项结果、阻断、未知和完成状态 | 内容未变复用；变更只重检受影响类别；未知不假通过 |
| 最终确认/退回 | 对象版本、动作、理由（必要时） | 权威确认与可交付性 | 变更冲突需重审；前端不可自行放行 |
| 同页生成/取消导出 | 最终确认版本、格式、许可处理、幂等键 | 状态与下载结果 | 重复一致；失败不生成损坏成功文件或清空确认 |
| 删除/撤销删除任务 | 精确目标、影响确认、基线版本、幂等键 | 立即隐藏；宽限内可撤销；到期后终态 | 重复一致，不泄露归属；P11 不恢复 |

## 6. 列表、分页与筛选

- 可选史料列表默认先显示 4—6 条优先推荐，再显示更多可用结果；不可用/核验中结果与可选区隔离。排序来源必须能解释问题匹配、来源/定位、类型与观点互补、学段/课时和权利边界，不显示伪精确总分。
- 页码或游标是实现待定；前端只要求 `items`、`hasMore/total`（至少其一）、稳定排序说明和可恢复视图位置。
- 筛选条件由 adapter 声明支持项；URL 使用稳定值。清除筛选后恢复全量数量。
- 超过 50 条时前端编码阶段验证分页/虚拟化；不预设数据库查询或索引。

## 7. 离线、缓存与并发需求

- Demo：IndexedDB 中保存版本化任务快照，迁移失败时不静默丢弃；任务菜单提供任务管理，不宣称服务端清除。
- 完整模式：页面需要区分 fresh/cached/pendingSync；离线编辑是否允许按动作逐项声明，批准/核验/审计/删除不得假成功。
- 所有可编辑对象需要基线版本或等价冲突证据；冲突返回当前权威版、教师草稿和安全下一步。
- 恢复联网不会自动重放可能产生费用、批准、导出或删除的动作。

## 8. 后续设计验证问题

阶段 7 已从领域关系而非页面结构完成数据设计，见 `../04-database-design/`；它不改变本文件的前端可观察契约。阶段 9 仍须决定 HTTP 路径/方法、请求限制、鉴权、错误码、SSE/轮询和幂等实现；若改变前端可观察行为，退回阶段 5。游标格式和在线事件协议仍未决定；文件摄取不在 v0.1，导出格式库已由阶段 6 实现确定。

字段命名、adapter 能力、fixture 根包、场景注入和具体 JSON 形状由 `VIEW-MODEL-FIXTURE-SPEC.md` 冻结；逐页字段与文案以 `PAGE-SPECIFICATIONS.md` 为准。三者冲突时先修订设计，不在编码中任选一份。

## CP-11-03 本地栏目草稿与采用

`reviewedContent?: Record<string, unknown>` 是 adoption 可选字段，按 purpose 对应既有完整分项 Schema 严格校验。省略时仍原样采用；提供时将教师编辑后的分项和生成记录关联，在现有事务内一次保存。If-Match、baseLockVersion、workspace/task、来源/引用与等待教师状态均不变。幂等摘要含最终确认内容。

本地 UI 将生成结果转换为相应 Draft，只替换目标字段或卡片。待确认、撤销栈与手工编辑仅在当前窗口内存中，正式内容保持服务器版本；刷新可恢复原始 generated revision，但不能恢复未保存手工修改。确认前不进入签发或导出。证据关系 Draft 的可选 `citations` 保留 sourceVersionId/chunkId/quotedText，改理由不丢原始引用；缺失短引明确提示，不伪造核验。

相同合成输出可对应不同 model run；generated snapshot 包含由 Worker 写入的 `modelRunId`，原始 proposal 不改写。再次生成只取入队冻结边界之前的完整保存修订，不能拿待确认建议冒充完整课程上下文。

用户后续批准 Demo 同步：Demo 不使用 adoption API 或后台 job。预生成 Draft 在页面加载时直接投影，恢复示例/撤销只改变本机 Draft 并沿用 IndexedDB 保存；不写入本地完整模式的待确认缓存或服务器。初次检查理由为明确标注的演示预设，不能当作真实教师决定；已保存用户修改不被清空。本地模式仍按 CP-11-03 执行真实版本和事务门禁。
