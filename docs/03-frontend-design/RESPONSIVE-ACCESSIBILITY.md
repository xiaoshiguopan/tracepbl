# 响应式与可访问性规则

> 状态：阶段 5 已批准归档
> 目标：WCAG 2.2 AA 设计与测试目标；不宣称认证

## 1. 响应式策略

移动优先，断点由内容失真触发，不按设备品牌命名：

| 层级 | 条件 | 布局 |
|---|---|---|
| Compact | `< 640px` | 单列；步骤摘要；卡片/定义列表；底部动作非固定或使用安全区 |
| Medium | `640—959px` | 单列主任务 + 可折叠辅助面板；筛选抽屉；双列短表单可选 |
| Wide | `960—1279px` | 左侧脉络带 240px + 主内容；详情在同页下方/侧面由容器决定 |
| Canvas | `≥ 1280px` | 脉络带 + 主区 + 条件性证据详情；总宽不超过 1440px |

组件优先使用容器查询：候选卡在自身宽度超过 560px 时从纵向变两栏；量规维度超过 680px 才用等级横表。字体和间距使用有上下限的流式值。CSS 逻辑属性支持未来书写方向，避免硬编码 left/right 作为语义。

## 2. Compact 具体取舍

- 不缩小或隐藏来源状态、许可、教师批准、审计阻断；它们移到卡片标题下方的状态摘要。
- 主张—证据默认等价列表；“图形概览”是可选次入口。
- 宽表格变逐项卡片/定义列表；只有史料原始图像允许局部横向平移，且必须有文字定位替代。
- 筛选用全宽 disclosure/sheet；已应用筛选以可删除文本 chip 显示，并有“清除全部”。
- 触控目标推荐至少 44×44px，同时不低于 WCAG 2.2 的 24×24px 最低条件。
- 不使用 `100vh` 固定关键区域；采用动态视口单位并为安全区留白。
- 固定/粘性头尾不得遮住焦点、错误或最后一行内容；底部动作区加入 `safe-area-inset-bottom`。
- P00 移动端只加载从现役影片终帧提取的 172,306 B WebP，不下载桌面 MP4，也不请求陀螺仪或设备方向权限。桌面下三分之一信息轨在 Compact 改为底部单列：标题、用途、全宽文字入口依次排列，仍是独立 DOM 内容；完整边界由可访问的“公开演示”说明提供。项目全程无声。

## 3. 键盘与焦点

- 全闭环仅用键盘完成；无键盘陷阱。Tab 顺序与视觉顺序一致。
- 每页第一个可聚焦元素是“跳至主内容”；随后是全局导航、步骤导航、页面内容。
- 使用 `:focus-visible`，指示至少相当于 2 CSS px 外圈、相邻颜色对比至少 3:1；不无替代地移除 outline。
- sticky header、toast、抽屉和底部动作区不能遮挡焦点。程序性聚焦只发生在用户提交后的首错、打开对话框、路由页面标题或用户触发的结果区。
- 对话框焦点圈定并返回触发器；Esc 可关闭非阻断对话框。危险确认初始焦点在取消按钮。
- 拖拽、缩放和画布连线均有按钮/表单替代；活动排序有“上移/下移”，关系建立有“添加关系”。

## 4. 语义与读屏

- 一个页面一个 H1，标题不跳级；main、nav、aside、section、form、fieldset、table、dl 等原生语义优先。
- 按钮执行动作，链接导航；不使用可点击 div/span。
- 图标按钮有可访问名称；装饰图标从辅助技术隐藏；图片有语境化 alt，装饰图 `alt=""`。
- P00 的预渲染影片和静态海报是装饰层，从辅助技术隐藏；同等功能由真实标题、短说明、进入动作与“演示说明”表达，不为每一帧播报变化。
- disclosure 为按钮并同步 expanded；tabs、dialog 等仅在确实匹配模式时使用 ARIA APG。
- 图形证据关系有完整等价列表；节点的可访问名称包含对象、状态和关系摘要。
- 异步成功/保存状态用 polite live region；持续进度不每秒播报；错误在页面/字段中持久显示。

## 5. 表单与认知可访问性

- 所有控件有持久文字标签、目的说明、示例和关联错误；placeholder 不代替标签。
- 正确使用输入类型与 input mode；不阻止粘贴；非认证字段避免被密码管理器误识别。
- 必填、可选、“暂不确定”均用文字。重复信息尽量沿流程带入，但允许教师确认/修改。
- 校验先在字段离焦时温和提示，提交时完整校验；错误摘要链接到字段，焦点落首错。
- 超长表单按任务分组而非一次展示；系统只追问会改变材料、活动或评价的内容。
- 删除、覆盖、重新生成和上游改变在确认前显示影响；不用复杂验证码式确认。

## 6. 视觉、缩放与运动

- 正文对比至少 4.5:1，大字至少 3:1；非文本边界和焦点至少 3:1。状态不只靠颜色。
- 320 CSS px 和 200% 文本缩放下不出现双轴滚动，不丢核心操作；400% 缩放的可回流性在编码阶段纳入人工抽查。
- 用户可缩放；禁止 `user-scalable=no` 和限制最大缩放。
- 普通界面行距约 1.6—1.7；长中文史料使用 17—18px 正文、1.75—1.85 行高和受控栏宽，保留段落与引用定位。正文背景必须无纹理、低眩光；不把扫描影像或灯光放在文字背后。
- 尊重 reduced motion；无闪烁。P00 的 7.5 秒影片从第一帧可操作；reduced-motion 直接显示同片静态终帧。其余页面没有超过 5 秒的自动动画。
- 项目全程无声；不创建声音控件、自动播放状态或本机声音偏好。

## 7. 错误、状态与时间

- 错误、阻断、警告、未知、待复核和成功均有独立文本词汇与图标。
- 2 秒内反馈；30 秒显示耗时/取消；进度不可测时不伪造百分比。
- 离线 banner 说明哪些操作仍可本机完成、哪些尚未同步/确认；恢复联网不自动重做高费用或批准动作。
- 日期时间用本地化格式并明确“北京时间”；追踪 ID 可复制但不抢视觉主位。

## 8. 编码阶段验证规格

| 项目 | 设计验收 | 计划证据 |
|---|---|---|
| 键盘主链 | 从 P00 到 P10 无鼠标可完成 | Playwright + 人工键盘记录 |
| 焦点 | 路由、首错、对话框、抽屉和 toast 行为符合规则 | 组件测试 + 浏览器录屏/截图 |
| 窄屏 | 320px 无主任务水平滚动，关键信息不消失 | Playwright 视口截图 + 人工核对 |
| 缩放 | 200% 不丢操作；关键页 400% 回流抽查 | 浏览器人工记录 |
| 读屏 | 页面标题、步骤、表单错误、审计结果和关系列表可理解 | NVDA/浏览器人工抽查 |
| 对比 | 令牌及状态组合达标 | 自动对比/axe 类检查 + 人工检查 |
| 减少运动 | 所有非必要动画关闭/简化 | 媒体查询测试 |
| 3D 降级 | 完整/轻量/静态/纯色四级均可立即进入；上下文丢失不影响焦点 | 浏览器故障注入 + 人工记录 |
| 晕动与输入 | 视差幅度克制；无自由漫游；手机无方向权限请求 | 桌面鼠标、触摸与真实设备人工验证 |
