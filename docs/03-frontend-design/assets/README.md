本目录只保存前端设计阶段的视觉验证资产，不是正式前端代码或历史史料库。

## `dunhuang-hero-art-direction-v1.png`

- 用途：P00 混合 3D 首屏的第二关键帧/色彩方向参考；验证空间、人物尺度、矿物色与灯光气质，不代表完整动画已制作。
- 阶段 6.4 状态：`hero-desktop-v1.svg/png` 为已否决版式的历史评审资产，不再作为当前 P00 验收基准；当前基准见 `apps/web/public/assets/p00/p00-film-keyframe-*-v1.webp`。
- 生成方式：2026-08-31 使用 Codex 内置图像生成能力生成，并进行一次“移除伪可读文字”的定向修订。
- 性质：**AI 艺术化演绎，不是历史照片、壁画复制品、考古复原图或可引用史料**。
- 事实锚点：1900 年敦煌藏经洞重现于世；最终界面中的历史事实仍须来自权威公开来源并单独标注。
- 使用限制：不得裁掉“艺术化演绎”说明后冒充史料；不得从画面推断服饰、人物相貌、洞内陈设或具体历史细节；阶段 6 若使用，必须生成响应式派生尺寸并验证体积、对比度和文字可读性。
- 视觉限制：卷轴和壁面不得出现可被误认成真实史料引文的生成文字；若后续检查发现伪文字或事实误导，立即替换或停止使用。
