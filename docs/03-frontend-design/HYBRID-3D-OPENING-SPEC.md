# P00 混合 3D 开场规格

> 版本：0.1
> 日期：2026-08-31
> 状态：阶段 5 已批准归档
> 边界：定义可观察体验、资产分层和验证门；不选择或安装运行时依赖，不包含正式前端代码

## 1. 体验命题

用户不是在观看一段必须播完的宣传片，而是从第一帧站在一个可进入、会呼吸的敦煌藏经洞空间中。王圆箓以历史见证者而非英雄或反派的姿态提灯进入；灯光唤醒洞窟、经卷和壁画人物的空间层次。镜头最终穿过一卷展开的空白残卷，纸面转化为明亮证据工作台。

画面采用由敦煌壁画材料语言生长出的现代 3D 动画电影风格：人物具有雕塑感，矿物颜料进入材质与光影，但不模仿任何具体影视作品，不追求真人或纪录片写实。

## 2. 为什么采用混合 3D

| 层 | 表现方式 | 目的 |
|---|---|---|
| 王圆箓与主镜头 | 高质量预渲染动画/序列 | 保证人物表演、衣料、灯光和镜头达到动画电影质感，避免廉价实时角色 |
| 洞窟空间 | 前/中/后景深度层或简化实时几何 | 提供真实摄像机微位移和遮挡层次 |
| 灯火、尘埃、纸页剪影 | 数量受控的实时增强 | 让空间回应鼠标/触摸而不主导叙事 |
| 展开残卷 | 实时或可同步的空间转场层 | 把暗场有意义地转化为工作台，而非生硬切页 |
| 真实 UI | 独立 HTML/语义层 | 第一帧可读、可操作、可聚焦，不受 3D 加载或失败影响 |

“混合”是质量策略，不是假 3D：用户仍能感到镜头深度、遮挡和轻微视差，但不要求每个人物与经卷都成为可自由观察的实时模型。

## 3. 5—7 秒导演式镜头

| 时间 | 镜头与画面 | 声音 | 可操作行为 |
|---:|---|---|---|
| 0—1.5s | 近黑洞窟中出现一点灯火；从王圆箓背后进入，保留 UI 暗部 | 极轻洞窟风声和火焰 | 标题、进入、边界和声音开关已可用 |
| 1.5—3.5s | 肩后镜头缓慢前推；灯光揭示经卷纵深，壁画人物只随光产生极弱“苏醒感” | 加入衣料与远处纸页摩擦 | 鼠标只影响不超过安全幅度的视差；交互立即收束镜头 |
| 3.5—5s | 少量远去纸页剪影与消失的微光隐晦表达流散；不演成冲突或奇观 | 低频音乐极弱进入，不增大响度 | 不出现弹窗、热点说明或必须点击对象 |
| 5—7s | 一卷无可读文字的残卷向镜头展开；纤维纸面逐渐变亮并转化为工作台画布 | 环境声自然淡出 | 已选择进入时直接同步到转场末帧；不等待动画播完 |
| 7s 后 | 停在动态终态，只保留灯火、尘埃和极轻空间呼吸 | 不连续堆叠音乐 | 页面保持稳定，不循环重演人物动作 |

## 4. 镜头和环境回应

- 主镜头由导演式时间线控制；用户不能自由漫游、旋转到洞窟背面或改变叙事顺序。
- 桌面鼠标只产生微小摄像机位移和前/中/后景差速，不能让标题漂移、晕动或露出场景边缘。
- 人物、壁画或经卷在指针靠近时只以灯光和材质产生轻微回应；没有工具提示、收藏点、游戏化奖励或寻物任务。
- 滚动、键盘导航、点击“进入证据工作台”或路由改变都立即把镜头平滑收束到残卷转场；不提供“跳过片头”门槛，因为内容本来就未被片头阻挡。
- 王圆箓主要为背影和肩后视角，面部仅可在灯火侧影中短暂出现；不得使用正面英雄特写或确定未知相貌细节。

## 5. 真实 UI 与 3D 的边界

- 主标题“让沉睡千年的证据重新开口”、副标题、`1900`、演示边界、艺术化演绎声明、进入/继续任务和声音开关均是独立真实文本。
- 3D 画面不生成标题、馆藏号、引文、经卷文字或状态；所有纸面只允许纤维、污渍和不可构成字符的抽象墨色节奏。
- UI 固定在安全可读层，镜头视差不改变点击目标位置；3D/视频/Canvas 使用装饰语义并不进入辅助技术阅读顺序。
- 艺术声明为“艺术化演绎，不是历史照片或可引用史料”，不能因 3D 更逼真而缩小或隐藏。

## 6. 首次、再次访问与重看

- 第一次访问且满足完整体验条件：自动运行一次 5—7 秒镜头。
- 同一设备再次访问：直接停在动态洞窟终态，不自动重播主镜头。
- 提供次要入口“重看序章”；只有用户主动触发才完整重播。
- 进入任务后通过浏览器返回 P00，不自动重播；任务数据和镜头偏好分离。
- 本机只记录 `introSeen`、声音和运动偏好，不创建跨站标识或设备指纹。

## 7. 渐进增强与降级梯

系统按能力、偏好和预算选择最高可安全运行的一级，任何一级都保留同一构图、真实 UI 和主动作：

1. **完整混合 3D**：预渲染人物主镜头 + 实时空间/灯火/尘埃/视差/残卷转场。
2. **轻量动态**：响应式预渲染片段 + 受控二维深度层；关闭实时粒子和自由摄像机位移。
3. **静态终帧**：同构图静态图 + 极轻 CSS 灯光淡变；适用于低性能、加载失败或数据节省。
4. **纯色安全首屏**：`narrative-void` + 全部真实文字和操作；媒体资源完全失败时使用。

`prefers-reduced-motion: reduce` 直接进入静态终帧，不播放推镜、视差、漂浮纸页或残卷自动转场。手机不请求陀螺仪/设备方向权限，只允许极小触摸视差；容易晕动或低帧率时自动降级。

## 8. 声音设计

- 单一克制声景：极轻洞窟风声、火焰、衣料和远处纸页摩擦，加几乎不可察觉的低频音乐；无旁白、诵唱、突然冲击声或“史诗鼓点”。
- 穿过残卷时自然淡出，工作台保持安静。
- 默认偏好为开不等于保证自动有声；被浏览器阻止时等待首次用户激活，失败不弹错误。
- 声音开关始终可见、可键盘使用并记住本机偏好；页面进入后台立即暂停。

## 9. 资产和历史诚信

- 预渲染角色、洞窟、壁画、经卷、音频和派生帧分别进入资产登记；记录生成/制作方式、作者、许可、是否史料、修改和体积。
- 王圆箓服饰、灯具与洞窟陈设必须先依据官方权威材料建立“已知/推断/艺术处理”清单；未知相貌和现场细节不得写成复原事实。
- 壁画采用材料语言的原创艺术设计，不能把具体未授权洞窟壁画高清复制进公开 Demo。
- AI 生成关键帧只是美术探索，不能成为历史来源；出现可读或伪可读文字的生成图一律不得进入项目正式资产。

## 10. 阶段 6 双门禁

### 10.1 技术原型门

目的只验证能力，不验收最终美术。必须证明：

- UI 第一帧可操作，3D 加载、崩溃和降级均不阻断进入；
- 导演式镜头、鼠标微视差、交互收束、残卷转场、再次访问和重看状态可运行；
- reduced-motion、手机轻量级、后台暂停、声音开关和失败降级符合规格；
- 真实设备记录加载时间、传输体积、帧率/卡顿、内存压力和输入延迟；
- 若现有依赖不足，先提交最小依赖选择及体积/维护/许可证据并获得用户批准，未经批准不得安装。

技术原型可以使用几何占位和低清临时资产，但必须醒目标注“技术原型”，不能作为阶段 6 最终视觉完成证据。

### 10.2 最终视觉验收门

替换为经审查的最终人物、洞窟、灯光、声音和响应式派生资产后，必须验证：

- 达到原创现代敦煌 3D 动画电影质感，不像真人实拍、现成游戏素材或对某部作品的模仿；
- 王圆箓、流散暗示和残卷转场符合已批准叙事，不出现英雄化、猎奇化或伪史料文字；
- 3D 与工作台颜色、纸面转场和文字层形成同一系统；
- 完整、轻量、静态和纯色四级视觉身份一致；
- 性能、可访问性和资产许可全部通过，技术原型标识和临时资产清零。

只有两个门均通过，P00 才能计入阶段 6 前端编码完成。

## 11. 失败与发布阻断

- 3D Canvas/媒体错误：立即保留静态或纯色首屏，记录安全诊断，不显示浏览器堆栈。
- 帧率持续不足、设备发热、输入延迟或明显眩晕：自动降一级，不要求用户自行忍受。
- 人物或材质质量呈现廉价游戏感：不得用“技术已完成”替代视觉验收。
- 任何阻塞主操作、抢焦点、无法关闭声音、reduced-motion 仍推镜、伪可读文字、未授权壁画复制或艺术图冒充史料，均为发布阻断。
