# P00 预渲染电影开场规格

> 版本：0.4
>
> 日期：2026-09-01
> 状态：阶段 6.4 根据用户审美复核重写；首版 H3 成片已接入，仍须通过最终视觉门

## 1. 体验命题

P00 是一段从第一帧即可进入任务的 5—7 秒无声动画电影镜头。王圆箓以背影或肩后视角提灯进入敦煌藏经洞；摄影机以明确的推进、揭示和收束建立冲击力。结尾接近一张有实体支撑的展开纸面，再与 P01 低眩光史料阅览台建立材质连续性。

画面是“敦煌壁画人物被现代 3D 动画重新唤醒”的艺术化 CG，不是历史照片、考古复原或可引用史料。人物不使用英雄式正面特写，不声称复原未知相貌。

## 2. 第一性原理选择

用户要的是电影摄影、角色表演、灯光、材质和镜头节奏，而不是浏览器里可以旋转的 3D 对象。因此正式方案是：

| 层 | 实现 | 职责 |
|---|---|---|
| 主视觉 | 预渲染无声 WebM/MP4 | 承担人物、洞窟、摄影机、灯火和电影节奏 |
| 静态回退 | 同构图响应式 WebP | 省流量、减少动态、解码失败和窄屏回退 |
| 真实 UI | React/HTML/CSS | 品牌、标题、边界和唯一进入动作；第一帧可读可操作 |
| 页面衔接 | 原生 History API 立即切页 | 不增加独立转场层；空间连续性由影片纸面尾帧与工作台材质承担 |

Three.js 技术原型已经证明渐进增强能力，但其纸片、粒子、指针光点和程序化镜头未达到用户要求，正式体验不再加载该运行时。依赖清单的清理需在允许修改依赖文件的门禁内另行执行。

## 3. 镜头节奏

| 时间 | 画面 | 节奏 |
|---:|---|---|
| 0—1.2s | 黑暗中灯火切开空间，王圆箓进入 | 快速建立方向，不做平滑淡入 |
| 1.2—3.8s | 肩后推进，灯火连续揭示洞窟纵深、经卷和壁面 | 明确加速、短暂停顿、再次推进 |
| 3.8—5.5s | 摄影机越过人物，空间尺度突然打开 | 全片冲击峰值；没有漂浮白纸或魔法粒子 |
| 5.5—7s | 镜头逼近实体支撑的展开纸面，纸面占满画幅 | 为工作台匹配剪辑，不做飞行残卷隧道 |

点击 `进入史料工作台` 在任意时刻立即进入 P01，不等待影片播完，也不出现第二个按钮。最终成片可在点击时寻址至尾帧或直接切到纸面匹配点；若浏览器/编码不支持，则短促交叉淡化或立即切页。

## 4. UI 构图

- 影片全屏铺底，顶部只保留品牌与低权重“作品集演示模式”。
- 首屏不显示 `1900 · 敦煌藏经洞`；底部使用贯穿安全区的电影下三分之一信息轨：标题在左、产品用途在中、唯一入口在右，共享一条基线和克制的顶部分隔线，不能形成互不相关的视觉孤岛。
- 标题两行同字号同颜色；用途固定为 `面向历史教师的可追溯史料探究工作台`。入口保持真实 `button`，但视觉呈现为透明文字动作与旧金细底线，不使用带底色、阴影或完整描边的卡片按钮。
- “敦煌序章不是本课史料”等解释性句子不占据主视觉；完整诚信边界收进顶部低干扰“演示说明”，不增加第二次确认。
- 影片和回退图均从辅助技术树隐藏；完整功能由真实标题、短说明、进入动作和可访问的演示说明表达。
- 首页只使用一次与画面曝光节奏一致的标题显影和信息到达；入口仅在 hover/focus 时增强底线与箭头位移。不得出现整体呼吸缩放、循环边光、漂浮纸片、粒子、洞壁光点或独立转场遮罩。

## 5. 无声、响应式与可访问性

- 项目全程无声音频、音乐、旁白、音效和声音控件。
- `prefers-reduced-motion: reduce` 只显示静态关键帧并立即切页。
- 窄屏将同一信息轨改为单列，标题、用途、全宽文字入口按阅读顺序排列在底部深色安全区；不得将桌面影片粗暴中心裁切后遮住人物、灯火或标题。
- 影片不接收焦点或指针；唯一主动作保持至少 44px，键盘焦点清晰。
- 媒体加载、解码或自动播放失败不能阻断标题、边界或进入动作。

## 6. 资产与诚信

- 成片、关键帧、海报和派生文件必须登记制作方式、版本、尺寸、体积、权利和“非史料”属性。
- AI 关键帧仅作为美术探索与回退画面；不得含可读或伪可读文字、印章、馆藏号或未经授权的具体壁画复制。
- 当前 `p00-film-keyframe-reveal-v1.webp` 与 `p00-film-keyframe-matchcut-v1.webp` 是镜头方向基准，不是影片成片。

## 7. 完成门

P00 只有同时满足以下条件才可宣称完成：

1. 有真实 5—7 秒预渲染成片，而不是 CSS 缩放、图片轮播或实时纸片替代；
2. 画面达到用户确认的高级动画电影 CG 质感；
3. 一次点击、无声、静态回退、窄屏和减少动态均通过；
4. P00→P01 匹配剪辑无飞纸、白洗、门户光圈或重复确认；
5. 浏览器、性能、资产权利和历史诚信门全部通过。
