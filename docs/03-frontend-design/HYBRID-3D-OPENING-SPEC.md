# P00 预渲染电影开场规格

> 版本：0.5
> 日期：2026-09-05
> 状态：用户已确认 H3 V2 画面、色彩、运镜与最终剪辑；本文件取代此前的洞窟叙事方向

## 1. 体验命题

P00 是一段从第一帧即可进入任务的 7.5 秒无声动画电影镜头。它不讲述具体历史事件，也不使用藏经洞、历史人物或仿古旅游宣传片意象；它把“证据被重新唤醒”抽象为笔锋、山河、道路与日轮的视觉旅程。

画面使用明亮而有层次的朱砂红、钴蓝、青绿、暖金和象牙白矿物色。质感来自手绘笔触、清晰空间层次和电影化速度曲线，不通过黑场、左右晃动、快速摇摆、CSS 缩放或粒子特效制造伪冲击。

## 2. 实现分层

| 层 | 实现 | 职责 |
|---|---|---|
| 主视觉 | 预渲染 H.264 MP4 | 承担笔锋收卷、镜头加速、构图匹配、山河揭示和终帧稳定 |
| 静态后备 | 从成片终帧提取的 WebP | 窄屏、减少动态和解码失败时保持同一视觉世界 |
| 真实 UI | React/HTML/CSS | 品牌、标题、演示边界和唯一进入动作；第一帧可读可操作 |
| 页面衔接 | 原生 History API 立即切页 | 用户点击即进入任务，不等待影片播完，不增加独立转场层 |

页面不得再加载旧视频、旧主题海报或关键帧，也不得叠加 CSS 摄影机运动来修改成片节奏。

## 3. 镜头节奏

| 时间 | 画面 | 节奏 |
|---:|---|---|
| 0—1.4s | 朱砂、群青与象牙白笔锋在画面前景建立环绕关系，随后自然收卷 | 先建立视觉因果，再把视点吸入；不得突兀硬穿越 |
| 1.4—4.0s | 视点进入蓝绿山谷，沿明亮道路持续前推 | 使用清晰的加速度曲线，不匀速、不左右摇摆 |
| 4.0s | 太阳、道路和蓝色山体完成直接构图匹配 | 不叠化、不白洗，接缝必须在运动与构图上连续 |
| 4.0—6.4s | 镜头继续加速并攀升至山脊 | 前进方向明确，速度变化平顺，不做机械上移 |
| 6.4—7.5s | 宏阔群山、河流与日轮完整打开 | 减速后稳定定格，形成史诗终态和文字安全区 |

点击“进入史料工作台”在任意时刻立即进入 P01，不出现“跳过片头”、二次确认或等待门槛。

## 4. UI 构图

- 影片全屏铺底；顶部保留品牌、任务入口和低干扰“公开演示”说明。
- 底部使用贯穿安全区的电影下三分之一信息轨：标题在左、产品用途在中、唯一入口在右；窄屏按相同阅读顺序改为单列。
- 标题固定为“让沉睡千年的证据 / 重新开口”，用途固定为“面向历史教师的可追溯史料探究工作台”。
- 入口使用真实 `button`，视觉为透明文字动作与细底线，不做卡片式方框。
- 媒体从辅助技术树隐藏；可读标题、入口和 Demo 边界由 HTML 提供。
- 鼠标微光只可轻微响应指针位置，不承载信息、不移动镜头；触屏和减少动态环境关闭。

## 5. 无声、响应式与失败恢复

- 媒体文件物理上没有音频流；页面仍设置 `muted` 和 `playsInline`，项目不提供声音控件。
- 桌面且未启用 `prefers-reduced-motion` 时从头播放一次，不循环；结束后保持最后一帧并显示低权重重播按钮。
- 窄屏和减少动态环境显示成片终帧海报，不下载或播放旧主题媒体。
- 视频解码或加载失败时立即显示同一终帧海报；标题、边界和进入动作始终可用。
- 强制高对比模式可隐藏纯装饰媒体，但不能隐藏真实内容和操作。

## 6. 资产与诚信

- 成片、海报和字体必须登记版本、尺寸、体积、哈希、制作方式、权利与“非史料”属性。
- 画面不得含可读或伪可读文字、印章、馆藏号、水印，不能冒充真实史料或历史复原。
- 仓库只保留最终成片、其静态后备和必要字体；分段原片、参考图、接缝试片、生成响应与密钥不得进入项目。
- 当前唯一媒体事实以 `docs/06-development/P00-FINAL-ASSET-REGISTER.md` 为准。

## 7. 完成门

P00 只有同时满足以下条件才可宣称完成：

1. 7.5 秒 H.264 成片为 1344×768、24fps、180 帧且无音轨；
2. 用户确认的笔锋吸入、加速前推、构图匹配和史诗终帧均保留；
3. 旧视频及旧运行时图像不再存在于生产资产或构建产物；
4. 单次播放、终帧保持、重播、静态后备、窄屏、减少动态和失败回退可观察；
5. 类型检查、规范检查、组件测试、生产构建与真实桌面/移动浏览器验证通过。
