# 阶段 5 学习卡

## 1. 你刚刚完成了什么

你完成的不是一组“好看的页面”，而是一套可以直接施工的前端设计：教师如何完成证据探究、13 个页面如何衔接、各种失败怎样恢复、手机和键盘如何使用、组件和数据状态放在哪里，以及 Demo 怎样在不接真实后端的情况下忠实演示这些行为。

视觉上也已经从抽象偏好变成可检查的方案：以 1900 年敦煌藏经洞为品牌序章，王圆箓提灯进入由壁画材料语言生长出的现代 3D 动画空间，再穿过展开的残卷进入明亮、克制的证据工作台。人物和艺术画面负责情绪，史料与出处负责事实，两者绝不混用。

## 2. 为什么必须在编码前完成

前端返工最贵的往往不是颜色，而是“页面到底做什么、状态冲突时谁优先、手机上哪些信息不能消失、动画是否阻塞、数据长什么样”。本阶段把这些高代价决定提前冻结，让编码主要变成实现和验证，而不是边写边发明产品。

## 3. 六个关键概念

1. **两幕视觉系统**：品牌序章可以有电影感，工作区域必须回到高可读、低疲劳的明亮界面；情绪与效率各在适合的位置。
2. **艺术层与证据层**：AI 艺术图必须标明是艺术化演绎，不能进入史料、引文或证据链；历史事实仍只依赖官方权威材料。
3. **状态归属**：可分享视图放 URL，编辑草稿放任务状态，动效偏好放本机环境状态，按钮悬停留在组件内部，避免刷新丢失和全局混乱。
4. **编码就绪门**：设计文件齐全还不够；只有字段、文案、复合失败、Mock、资产预算和冻结边界都明确，才算真正适合动工。
5. **混合 3D**：人物和主镜头可预渲染以保证品质，空间回应可实时计算；“是不是每个物体都实时”不如“用户能否得到稳定、真实的空间感”重要。
6. **双门禁**：技术原型回答“能否稳定运行”，最终视觉门回答“是否真的高级、有历史人文魅力”；前者不能代替后者。

## 4. 最容易踩的四个坑

1. 把隐藏按钮当成权限。前端权限展示只能改善体验，真正授权必须由服务端逐项强制。
2. 把生成的历史画面当成史料。艺术可以生成，史料、引文、出处、版本和权利不能生成。
3. 让“惊喜”挡住使用。动效必须可降级；首帧可操作，一次点击即进入，失败也不能影响主链。
4. 把能跑的几何占位当成最终 3D。人物、灯光、材质和转场没有通过最终视觉门，就仍是技术原型。

## 5. 你可以亲手检查的一件事

打开运行页面，强制重播 P00，再问四件事：能否一次点击进入任务、进入前后是否像同一个作品、能否明确知道画面是艺术化演绎、降为静态后是否仍可完成主链。四项同时成立，才是本项目所说的“高级感”。

## 6. 如果编码时发生分歧

先读 `FRONTEND-REVIEW.md` 的冻结表，再按问题查：3D 镜头和降级读 `HYBRID-3D-OPENING-SPEC.md`，页面行为读 `PAGE-SPECIFICATIONS.md`，状态冲突读 `PAGE-STATE-MATRIX.md`，视觉读 `VISUAL-DIRECTION.md`，数据读 `VIEW-MODEL-FIXTURE-SPEC.md`，性能与资产读 `BROWSER-PERFORMANCE-ASSETS.md`。如果变化会改动主链、状态语义、安全边界或跨层合同，必须重新走变更控制，不能在代码里悄悄决定。
