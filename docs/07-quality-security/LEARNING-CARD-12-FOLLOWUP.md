# 阶段 12 补验学习卡

日期：2026-09-05。对应 [补验报告](./STAGE-12-FOLLOWUP-REPORT.md)。

- 冷下载证明所需文件真的能从官方取得；无缓存构建证明安装过程重新执行；完整启动证明服务能共同工作。三者不是一回事。本机通过官方 Windows 下载补齐前两者，但 WSL 自己的网络失败仍如实保留。
- Windows 原生恢复是让实际 PowerShell 和 PostgreSQL 客户端处理备份，不只是检查脚本文法。旧备份恢复后还必须应用最新删除清单，防止已删除内容重新出现。
- 浏览器引擎通过不等于所有设备通过。WebKit 与 Safari 共用相关技术，但并不包含真实 Safari 的系统、读屏与字体组合。
- 覆盖率是代码执行比例，不是正确率。单元测试没有执行的界面代码必须算在分母中；跨层测试通过也不能直接加成单元覆盖率。
- 文件下载成功并不保证排版正确。这次真实 WPS 打开后发现孤立标题，只增加“标题与下一段同页”，再重新导出验证。
- 合成流程通过不授予真实 AI、敏感数据或公开部署权限。本轮不需要用户操作设备，但缺少设备的验证不能被写成通过。
