# 阶段 14.1 学习卡

- Public 仓库和公开网站是两件事。前者让人阅读源码，后者要上传正确的静态构建产物。
- GitHub Pages 没有本地开发服务器的自动路由兜底，所以本轮用真正 HTTP 404 来检验深层链接恢复。
- 手动发布与 CI 通过是两个门：CI 检验指定提交，人工批准控制这个提交是否公开部署。
- 精确推送 main 不等于镜像推送全部引用。本机工具快照可能包含工作区截图，不应随代码公开。
- 秘密扫描命中需要核对：本轮命中的是扫描器规则本身，不能因此写成真实泄露，也不能把 exit 1 改称通过。
- 项目许可证决定别人如何复用项目；字体和第三方素材仍按各自许可。账号、许可和具体外部动作必须在发布前明确。
- 本地模拟成功不代表公开 URL 已上线。必须记录实际 GitHub/Pages 运行和真实访客验证，再填写 README 体验链接。
