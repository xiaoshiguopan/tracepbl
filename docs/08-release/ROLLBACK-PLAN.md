# 静态 Demo 回滚计划

触发条件：公开入口或核心流程不可用、加载错误资源、意外连接 API/模型、公开内容出现秘密/隐私/权利问题、下载严重错误。

首发没有先前成功版本：先停止进一步发布，必要时经明确授权取消发布 Pages；不能谎称已回滚到不存在的旧版本。已有成功版本后：记录旧成功 SHA 和运行 ID，恢复经核验的静态候选，走同一受控发布流程。不要使用 force push 或改写 main 历史。

删除最新文件不能撤回已公开的 Git 历史或第三方缓存。发现真正秘密时停止发布，按已批准流程轮换并评估历史处理；不能用“仓库已改私有”保证泄露消失。

Pages 回滚不操作本地 PostgreSQL，也不删除访客 IndexedDB 数据。本版本没有服务器端一键恢复访客浏览器数据的能力。真实误发布时回滚操作仍需准确目标及相应外部授权。
