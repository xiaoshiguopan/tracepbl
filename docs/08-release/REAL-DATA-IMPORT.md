## 3. 按现有接口录入，不新增批量导入器

依据 `packages/contracts/src/index.ts` 的 MaterialInputSchema 和现役材料入口。以下仅为当前映射，不能绕过 API 直接写 SQL：

| 输入 | 现有字段/规则 |
|---|---|
| 材料标题 | name，去首尾空白，1—160 字符 |
| 文本 | kind=text；text 为 1—50,000 字符；不静默截断 |
| 链接元数据 | kind=url；url 为有效 URL，最长 2048 字符；本轮不抓取网页 |
| 处理权确认 | rightsAttestation=authorizedForCurrentTask 或 unknown；不能自动勾选 |
| 数据范围确认 | sensitiveInformationConfirmedAbsent=true；须先实际筛查，不是免责声明 |
| 接口结果 | 保存 sourceId、versionId 和 operation；202 不等于后台处理完成 |
| 选入任务 | 使用返回的 sourceVersionIds 与最新 If-Match；不得以标题代替来源版本 |

当前材料创建接口没有独立的作者、版本、定位、许可证明等完整结构化写入字段；读接口有这些字段，不代表创建接口可以传入。若真实批次必须逐字段保真，先对照具体样本评估；不能把字段塞进标题、伪造默认定位或用 SQL 补写。确需补公共接口时另走变更控制，本轮不实施。

UTF-8 为准备格式；时间用带时区的 ISO 8601，记录 UTC，展示可用 Asia/Shanghai。保留原文与加工区别；只清除无关字段，不擅自改史料措辞。用原始文件及准备文本的独立哈希记录转换，避免把规范化后的文本误称原文件。
