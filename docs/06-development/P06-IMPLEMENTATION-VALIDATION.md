# P06“设计活动”实现验证

> 日期：2026-09-02
> 范围：阶段 6.8，仅 P06 与 P05 相邻导航

## 1. 已确认设计合同

- 用户认可“45 分钟课堂排演稿”方案，并确认同视觉方向的桌面效果图后授权编码。
- 页面复用 P01 的灰绿色画布、米白纸面、宋体标题、矿物青操作色和克制细线，不采用普通教案表格或卡片墙。
- 唯一视觉签名是真实的 0—45 分钟连续刻度；每段固定突出 `学生动作 → 使用史料 → 留下成果`，结构本身表达证据不可绕过。
- 系统先排出一份可用方案，教师只需按需展开局部编辑；匿名学情只记录困难维度，不收集姓名、班级号、学生作品或个人画像。

确认图保留在 Codex 生成图片目录，未复制进项目或史料资产。

## 2. 数据、规则与恢复

- 默认三段任务分别为 8、15、16 分钟，三段转换各 2 分钟；任务 39 分钟、转换 6 分钟，总计 45 分钟。
- 每段保存名称、任务分钟、转换分钟、绑定史料、学生动作、可观察成果、困难、支架、教师编辑标记和复核状态。
- 活动使用 P02 中心问题、P03 当前史料和 P05 关系；不复制史料正文，不调用真实 AI、RAG、网络或后端。
- 若动作没有要求选择、引用、比较、质疑、标注或限定证据，或缺史料/成果/困难/支架，则不能确认。超时直接改变主动作并显示精确超出分钟数。
- IndexedDB 升至版本 5，新增独立 P06 草稿 store。问题变化影响全部活动；史料/关系变化只标记使用受影响史料的活动。
- 排序提供上移/下移；删除可撤销。局部替代建议先显示当前与建议差异，教师应用后只修改该段。

## 3. 真实浏览器证据

应用内 Chromium 已验证：

- P05 确认后进入 `/tasks/demo-tang-45m/lesson`；P06 可从证据脉络返回 P05。
- 桌面排演谱、三段连续刻度、动作—史料—成果链和右侧时间账簿可见；视觉与确认稿方向一致。
- 局部建议先展示差异，再应用到单段；活动上移、移除和撤销后数量与顺序即时更新。
- 校验失败聚焦唯一错误活动；超时示例显示 `先调整 12 分钟`，焦点进入时间账簿，不隐藏转换时间。
- 新标签页确认加载骨架；开发状态 URL 覆盖空活动、无史料、生成失败、30 秒超时、离线、不可用和成功反馈。
- 390×844 与 320×800 无主任务水平溢出；可见按钮没有低于 44px。窄屏先显示时间账簿，再显示单列排演稿。
- 键盘首焦点为“跳至主要内容”，焦点环为可见实线；页面无音频。
