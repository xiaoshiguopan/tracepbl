## 5. 风险、遗留和影响

- 当前安全首屏不是最终视觉资产，也不是混合 3D 技术原型；人物、镜头、残卷转场与环境声仍未制作。
- Playwright CLI 在 Linux 环境找不到 Chrome，因此没有擅自下载浏览器；等价的真实页面验证改由现有应用内 Chromium 完成。CLI 浏览器矩阵仍待后续已批准环境验证。
- 真实屏幕阅读器、`forced-colors`、200%/400% 缩放和主动模拟 `prefers-reduced-motion` 尚未完成；当前只有语义结构、计算焦点样式和 CSS 条件规则证据。
- Node 24.19.0、npm 11.17.0 比阶段 2 目标各低一个补丁版本；本子阶段验证通过，没有未经授权升级系统工具。
- P01—P12 尚未编码。P00 主动作只打开安全边界，避免假装任务链已经存在。
- 下一子阶段必须先提交 P00 混合 3D 技术原型及运行时依赖准入；技术原型不能冒充最终视觉验收。
