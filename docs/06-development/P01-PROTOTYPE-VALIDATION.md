## 2. P01 结构与视觉证据

- 2026-09-02 UX 复核后删除三幕：P01 只保留学段、年级、教材、课次、分钟以及可选课型/初步方向。
- 继续复用同一份 `TeachingContextDraft`、字段校验和 IndexedDB 草稿；右侧摘要直接由 draft 派生，没有复制状态、生成态或表单库。
- 桌面采用 13.5rem 深色步骤索引、低亮度矿物灰画布、中低亮度无纹理表单面和粘性条件摘要。
- 输入控件统一为 48px 基础高度、2px 圆角和一致内边距；多选/单选使用左侧矿物色标记，不再依赖白色圆角卡片套叠。
- 320×800 使用单列字段，当前情境摘要在表单后折叠；提交按钮高度 48px，避免页签往返。
- 合成示例说明改为低干扰 disclosure，删除与当前课堂无关的敦煌解释句。

## 3. 对教师任务的改进

1. 先用最少字段确定课程边界，初步方向允许为空，正式问题留到 P02。
2. 当前教学情境即时可见，不再先生成简报再二次确认。
3. 史料用途、数量和组成推迟到 P03 查找前；匿名学情推迟到 P06 设计活动与支架。
4. 只有一个确认动作；P02 未实现时不伪造跳转。
5. 核验完成前仍只称候选史料；前端步骤状态不冒充安全授权。
