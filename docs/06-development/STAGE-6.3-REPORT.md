## 3. 验证摘要

- lint、typecheck、2 文件 5 项测试和 production build 均以退出码 0 完成。
- 桌面 WebP 98,540B（预算 450KB），手机 WebP 40,934B（预算 220KB）；音频 384,044B，且不阻塞首屏。
- 初始 JS 63.56kB gzip；Three 仍是独立动态 chunk，131.18kB gzip，均在批准预算内。
- 应用内 Chromium：1440×900 完整层和 320×800 轻量层通过；手机选中专用 900×1200 WebP，无横向内容溢出，按钮至少 44px。
- 真实 Three 加载失败和 WebGL context loss 均回到静态图；纯色安全层不依赖图片；控制台 0 warning/error。
- 声音关闭后实际暂停，再开启后实际播放，音量 0.06；浏览器拒绝自动播放时不阻塞。
- 最终桌面和手机图经原尺寸与压缩后目视审查，无可读/伪可读文字、印章、水印或确定性正面肖像。

详细证据和未覆盖项见 `P00-FINAL-VISUAL-VALIDATION.md`。

## 4. 风险与边界

- AI 画面只能作为艺术化氛围，不能进入史料引用链；常驻声明和资产登记必须保留。
- 王圆箓的背影、洞窟结构和抽象壁面是叙事设计，不声称精确复原；未来有权威史料需求时必须另行采用官方公开来源。
- 当前音轨是合成气氛，不是历史声景复原；浏览器是否自动播放由平台策略决定。
- 当前应用内浏览器的键盘注入没有触发 Enter/Tab，因此完整人工键盘顺序、200%/400% 缩放、高对比和读屏留到发布前真实浏览器矩阵；焦点可见、原生语义、点击行为和响应式已有当前证据。
- Three 原始 chunk 触发 Vite 500kB 提示，但仍按需加载且 gzip 低于门槛；后续页面不得静态导入它。
- 没有新增依赖、P01—P12、数据库表/Schema、迁移、具体后端 API、真实数据、push 或部署。
