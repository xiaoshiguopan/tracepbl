# P07“评价量规”实现验证

> 日期：2026-09-02
> 范围：阶段 6.9，仅 P07 与 P06 相邻导航

## 1. 已确认设计合同

- 用户认可“从摘抄到历史解释的评阅标尺”方案，并确认同方向桌面效果图后授权编码。
- 页面延续 P01 的灰绿色画布、米白纸面、宋体标题、矿物青操作色和克制细线；主视觉是一张连续标尺，不是普通表单、评分表或卡片墙。
- 页面直接承接 P06 三项课堂成果；只评价证据选择与引用、证据解释、互证/质疑、结论及其边界，不比较标准答案，不生成权重或伪精确总分。
- 效果图由内置 ImageGen 生成，只用于用户确认，没有复制进仓库或作为史料。

## 2. 数据、规则与恢复

- 默认四个维度各含起步观察、证据成形、历史解释三段可观察行为，并明确映射到 P06 活动与成果。
- 教师可逐维修改名称和行为锚点；空白、重复或只写“优秀/一般/较差”等空泛描述时阻断确认并聚焦首错。
- 每维可请求一条预生成合成替代建议；先显示当前/建议差异，应用时只改变该维度。
- 删除维度可撤销，并明确提示会改变 MUST-007 四维覆盖；删除全部维度不能确认。
- IndexedDB 升至版本 6，新增独立 P07 草稿 store。P06 活动动作、成果、史料或状态变化时，只把映射到受影响活动的维度标记待复核。
- 不读取或保存真实学生、作品、成绩或姓名；权限可见性只是体验，不是真正安全授权。

## 3. 真实浏览器证据

应用内 Chromium 已验证：

- `/tasks/demo-tang-45m/rubric` 正常显示四维、三项成果、4/4 对齐及“不计算总分”；控制台无 warning/error。
- P06 确认后进入 P07；P07 可清洁返回 P06 及更早已完成步骤。
- 逐维替代先展示差异；应用只更新该维；删除后剩 3 维，撤销恢复 4 维。
- 校验失败显示空泛描述错误，并把焦点移到具体维度。
- 开发状态覆盖 5 秒加载骨架、空量规、缺课堂成果、生成失败、30 秒超时、离线、不可用和已确认成功。
- 390×844 与 320×800 的主任务横向溢出均为 0px；可见按钮没有低于 44px；窄屏把对齐校样放在评阅标尺之前。
- 首个 Tab 焦点为“跳至主要内容”，焦点环为 2.4px 实线；页面无音频。
