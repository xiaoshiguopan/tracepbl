# P09“最终确认与导出”实现验证

> 日期：2026-09-02
> 范围：阶段 6.11，仅 P09、P08 相邻导航及已确认的 P09 设计契约同步

## 1. 已确认设计合同

- 用户认可“教学包装订清样 + 一次教师签发 + 同页导出”方案，并在效果图后要求把中心问题字号调小、其余保持，随后明确授权直接编码。
- 页面延续 P01 的冷淡灰绿色画布、米白纸面、宋体标题、矿物青动作色和克制细线；正文是一张连续装订清样，不是卡片墙、仪表盘或重复审批表。
- P09 复用 P03 史料选择、P07 量规确认和 P08 设计检查等上游决定，只要求一次最终签发。清洁查看可以自由往返；上游内容实际变化后，签发快照失效。
- 中心问题使用正文重点级字号：1440px 下 19.44px，390/320px 下 16.8px，不复制效果图中过大的展示字号。
- 首版只使用浏览器原生打印窗口；不新增 `docx`、PDF 或导出依赖，不声称用户已经保存文件。

## 2. 数据、权利与恢复

- IndexedDB 升至版本 8，新增独立 P09 草稿 store；保存签发状态、签发时间、上游快照和文件名，不建立 P10 页面或第二套批准状态。
- 装订清样直接读取当前问题、4 条已选权威来源史料、3 段/45 分钟课堂活动、4 个量规维度和 17 项通过的设计检查。
- 四条史料只进入必要短引、事实性元数据、稳定定位和官方入口；馆藏图片、书影、全文和长篇馆方说明不进入打印内容。
- 文件名使用浏览器安全字符清理；非法字符清理后若只剩连字符、点或空格，阻断打印并聚焦输入。
- 本机保存失败、读取失败、上游缺项、设计检查未完成或失效时均不假签发。离线时仍可使用本机确认与打印，不自动触发任何外部动作。

## 3. 真实浏览器证据

使用 Codex 应用内 Chromium 验证：

- `/tasks/demo-tang-45m/review` 返回 HTTP 200，并显示连续装订清样、交付校样、权利处理预览、一次教师签发和同页打印区域。
- P08 采用首选建议并完成检查后真实进入 P09；P09 返回 P08 只查看后可再次进入，不要求重复处理。
- 点击 `确认这份教学包` 后文件名与 `打开打印预览` 解锁；点击打印入口出现持久反馈：`已打开系统打印窗口，请选择打印或另存为 PDF。`
- 输入 `<>` 后实际值被清理为 `-`，显示关联错误，`aria-invalid=true`，焦点回到文件名输入框。
- 加载、空史料、校验失败、系统失败、30 秒超时、离线、不可用、缺设计检查和成功状态均有独立可观察结果；未知或缺项不放行。
- 1440×1100、390×844 与 320×844 主页面横向溢出均为 0px；390/320 可见按钮最低 44px，交付校样在窄屏先于长清样。
- 首个 Tab 焦点为 `跳至主要内容`；页面只有一个 H1，没有音频；浏览器控制台 0 error、0 warning。

## 5. 未完成验证与风险

- 浏览器自动化验证了打印入口和准确反馈，没有代替用户在系统打印对话框中选择具体打印机或保存路径；应用无法可靠获知最终文件是否保存，因此不会声称“文件已生成”。
- 当前签发与权限都是前端 Demo 体验；真实读取、确认、导出授权和跨任务隔离仍须未来服务端强制。
- NVDA/VoiceOver、200%/400% 缩放、高对比及 Safari/Firefox 仍待发布前设备矩阵。
- 史料权利边界来自当前已登记公开来源 fixture；许可变化将要求重新核验，不能把当前必要短引规则泛化为公开再分发许可。
