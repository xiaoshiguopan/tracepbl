## 4. 未验证与风险

- 应用内浏览器的 Tab 键注入未移动焦点，因此只确认语义控件、程序焦点和可见焦点环，不声称完整人工 Tab 顺序通过。
- 200%/400% 缩放、NVDA/VoiceOver、forced-colors 的真实人工体验及 Safari/Firefox 尚未执行，保留到发布前设备矩阵。
- Demo 建议是确定性合成结果，只证明界面行为，不证明真实 AI 质量、服务端授权或未来完整模式隔离。
- 尚未进行真实教师可用性验证；若教师仍把页面理解成答题或不知道为什么要确认，应再次重开 P02 任务流。

## 5. 结论

P02 批准范围内的正常、加载、空、校验失败、系统失败、不可用、离线、超时、成功、回溯导航、窄屏和焦点行为已有当前证据。production preview 复验确认使用 P01 同款双栏、无旧巨型问题排版、无 P03 动作、P01/P02 清洁状态可双向切换，320px 无水平溢出、按钮最低 44px且控制台 0 warning/error。用户已批准本子阶段按精确路径本地归档；该批准不授权进入 P03。
