## 2. 画面来源与生成记录

- 生成工具：Codex 内置 OpenAI ImageGen；日期 2026-09-01。
- 性质：项目定制的 AI 艺术图，不声称复原真实藏经洞、真实壁画或王圆箓确切相貌。
- 构图指令：动画电影级 CG；洞窟真实空间结构中带适度艺术化；王圆箓只以背影/肩后视角提灯进入；人物是历史见证者而非英雄或反派；右侧经卷与抽象矿物色壁面形成纵深；展开的空白残卷成为视觉路径；左侧留出近黑文字安全区。
- 风格约束：兼容中国史与世界史的人文气质；近黑、矿物蓝绿、旧金与极少朱砂；克制、庄重、电影感；不复制任何具体电影、敦煌壁画或现成作品。
- 内容禁令：任何可读文字、伪文字、符号串、印章、题记、水印和界面元素；正面确定性肖像；血腥、猎奇、神化或贬损表达。
- 手机版：不是桌面机械裁切，而是重新安排人物、灯火、洞窟和下方文字安全区；首版残卷出现一个疑似印记后被明确拒绝，最终版重新编辑清除。
- 阶段 6.4 揭示帧指令：延续同一王圆箓与洞窟，摄影机从肩后明显前推并右移，灯火揭示洞窟尺度；禁止文字、印章、漂浮纸页、粒子与 UI。
- 阶段 6.4 匹配帧指令：摄影机逼近有实体支撑的展开古纸，纸面近正面占满画幅，为工作台匹配剪辑；禁止文字、印章、漂浮纸、白条、粒子和奇幻效果。

## 3. 衍生处理

项目只保留运行时仍需要的 WebP/JPG 派生文件，不把高分辨率生成母版打入公开站点。派生使用工作区已提供的 Sharp 运行时完成质量压缩；没有新增 npm 依赖，也没有图像内容修复、文字合成或历史材料拼贴。

桌面端以 H3 视频和 reveal 海报承担画面；窄屏继续用移动 WebP/JPG 回退。图片是纯装饰背景，使用空 `alt` 且从辅助技术顺序隐藏；真实标题、动作和艺术声明始终由 HTML 提供。

阶段 6.3 的 `p00-dunhuang-desktop.webp` 与 `p00-dunhuang-desktop.jpg` 在阶段 6.4 已被 H3 视频和 reveal 海报完全替代，运行时代码无引用；用户于 2026-09-02 看过精确清理清单并批准删除。原哈希保留在 Git 历史和阶段 6.3 报告中，可从历史恢复。
