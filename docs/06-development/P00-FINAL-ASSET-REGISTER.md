## 3. 衍生处理

项目只保留最终 WebP/JPG 派生文件，不把高分辨率生成母版打入公开站点。派生使用工作区已提供的 Sharp 运行时完成尺寸和质量压缩；没有新增 npm 依赖，也没有图像内容修复、文字合成或历史材料拼贴。

`<picture>` 按视口选择移动/桌面 WebP，并以同尺寸 JPG 回退。图片是纯装饰背景，使用空 `alt` 且从辅助技术顺序隐藏；真实标题、动作和艺术声明始终由 HTML 提供。

## 4. 环境声来源

音轨完全由本地确定性公式生成，不含第三方采样、真人录音、语音、吟诵、鼓点或受版权保护音乐：

- 随机种子 `1900`；
- 环形平滑噪声形成极轻洞风；
- 48Hz/71Hz 低幅正弦形成几乎不可察觉的空间底色；
- 五个合成衰减脉冲模拟微弱灯火；
- 低幅周期调制模拟布料/纸张运动。

播放器音量固定为 `0.06`，不阻塞首屏；浏览器拒绝自动播放时等待首次用户互动。用户可随时关闭，偏好只保存在本机；页面隐藏时暂停。它是气氛设计，不是历史声景复原。
