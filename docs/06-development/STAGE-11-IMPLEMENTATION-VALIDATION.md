## 2. 已定位并修复的失败

1. Compose 初始化只提供 migrator URL，而脚本读取了另一变量：统一 migration 入口；原错误未计通过。
2. Node 原生 strip 不支持参数属性：API/Worker 开发命令启用 transform-types，未安装新运行依赖。
3. 问题生成错误要求已有史料：问题建议只读取课程边界，证据/活动/量规继续执行 RAG 门禁。
4. 采用时额外锁 job 要求未授予的 UPDATE 权限：沿用同 task 事务锁核对待教师状态，未放宽角色权限。
5. 检索混用多个 embedding profile，重复 hit 触发唯一约束：检索、入库和种子明确选择同一批准 profile，模型/维度/distance 不变。
6. SSE 导航快速切换产生 429：立即发送连接注释，关闭/中断释放连接计数，代理释放上游连接；浏览器 offline 主动关闭、online 恢复。
7. 年级首次选择被学段联动清空：先确定学段再写年级，浏览器检查第一次选中即保留。
8. 宽限期结束撤销返回 500：映射为既定 409 `PURGE_ALREADY_STARTED`，不泄露 SQL/内部消息。
9. 缺少 If-Match 被通用 Zod 错误归为 422：恢复既定 428 语义；过期版本保持 412。
10. 审计只查部分内容，空课、超时或待复核内容可能被漏掉：补齐确定性缺项、引用/对齐、上游回退、超时阻断和有条件来源确认。
11. 受限来源导出误读当前内容：只从冻结快照投影，去掉受限正文、加工说明及引文；无网址时不编造链接。
