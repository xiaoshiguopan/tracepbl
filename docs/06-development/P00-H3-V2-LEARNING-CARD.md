# P00 H3 V2 学习卡

## 1. 你刚刚完成了什么

把用户最终确认的 7.5 秒影片正式接进首页，并让桌面、手机、减少动态和视频失败都落在同一个视觉世界；旧视频与旧主题回退文件已从生产资产和构建结果删除。

## 2. 为什么项目需要它

视频本身好看还不等于网页完成。如果手机仍显示旧图、构建仍打包旧 MP4，或影片失败后只剩黑屏，用户看到的产品仍会前后矛盾。这次接入把“成片、页面行为、失败回退、构建和文档”一起收口。

## 3. 三个新概念

1. **媒体流**：MP4 可以同时包含画面和声音。页面设置 `muted` 只是静音；本次文件只有 H.264 视频流，才是真正物理无声。
2. **静态后备**：手机、减少动态或解码失败时使用的一张图。本次后备直接来自成片终帧，所以不会突然换风格。
3. **构建残留**：Vite 会把 `public` 中未引用的文件也复制到 `dist`。只改组件引用不够，旧媒体文件必须从 `public` 删除并检查最终 `dist`。

## 4. 最容易踩的两个坑

1. 用新文件名覆盖引用，却把旧 MP4、海报或手机图留在 `public`，最终公开包仍会携带它们。
2. 用 CSS 额外摇摆、缩放或压暗已经定稿的影片，反而破坏镜头节奏、色彩和舒适度。

## 5. 你可以亲手做的一个小练习

在浏览器打开首页，等待影片结束后点一次“重新播放”；再把窗口缩窄到手机宽度。你会看到桌面重新从头播放，而手机只显示同一个史诗终帧，不会出现旧敦煌画面。

## 6. 如果出错，先看哪里

先看 `P00Experience.tsx` 中的新 MP4 和海报路径，再看浏览器 Network 是否只请求这两项；如果媒体参数可疑，用 `ffprobe` 检查时长、分辨率、帧数和是否存在音频流。
