# P05“组织证据”实现验证

> 日期：2026-09-02
> 范围：阶段 6.7，仅 P05 与 P03 相邻导航

## 1. 设计合同

- 用户先认可“史家论证批注桌”方案，再确认桌面效果图，随后明确回复“确认动工”。
- 实现沿用 P01/P03 的深墨绿框架、低眩光纸面、宋体标题、矿物青和细线体系。
- 默认界面不是空白关系图或长表单：系统先排出 3 个待判断命题、4 条关系和 1 处明确证据缺口，教师以确认、调整和保留缺口为主。
- 待判断命题均为问句；关系和理由明确标为预生成合成建议，不冒充历史结论或实时 AI。
- 图形不是唯一操作面；本版用可读、可编辑的批注式等价列表和右侧关系全貌满足概览需求，不实现拖拽、Canvas 或图形依赖。

确认图只保留在 Codex 生成图片目录，没有复制进项目、代码或史料资产。

## 2. 数据与恢复

- P05 读取 P02 中心问题和 P03 当前已选史料，只引用已登记的 `AUTH-SRC-*` 官方来源对象。
- IndexedDB 版本升至 4，新增独立 P05 草稿 store；不保存密钥、真实个人数据或史料全文。
- 草稿记录中心问题和史料选择快照。上游问题或史料集合变化时，关系降为“待复核”，不能继续假绿。
- P05 fixture 带版本号；仅缺版本的开发期旧空草稿会迁移为当前建议，教师在当前版本主动删空关系不会被偷偷重建。
- 删除关系提供最后一步撤销；重复命题—史料关系被阻止，新增关系 ID 不因中间删除而复用。

## 3. 状态与交互证据

真实 Chromium 已覆盖：

- P03 选择 4 条、多类型史料后进入 P05；P05 返回 P03 后可由证据脉络重新进入，状态保留。
- 调整首条关系类型、删除关系、撤销、确认整组关系和成功反馈。
- `?p05-state=loading|empty|empty-sources|validation|failure|timeout|offline|unavailable` 均显示对应可恢复状态。
- 校验失败保留草稿并聚焦相关命题；自动建议失败、超时或离线不锁住手工编辑。
- 390×844 和 320×800 均为单列、无主任务水平溢出，浏览器实测可见按钮最低 44px；证据账簿保留在正文末尾。
- 桌面 Tab 顺序从跳转链接、品牌、已完成步骤、后续步骤 disclosure、问题入口进入主任务；共享 `summary` 焦点由 0.8px 默认线补为 2.4px 可见实线。
- 当前页面控制台 0 warning/error。
