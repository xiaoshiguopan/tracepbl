
## P05 设计阶段

```text
请检查项目状态，只执行当前获准的一个阶段。顺序必须是：前端设计获批并归档 → 前端编码全部完成并归档 → 数据库设计获批并归档 → 数据库编码全部完成并归档 → 后端设计获批并归档 → 后端编码全部完成并归档 → 集成与总审查。每一层设计前不得提前处理该层代码，也不得提前设计后续层。所有开发、测试和联调只使用合成数据。结束后按标准格式汇报并等待我批准归档。
```

## P06 准备 Git 归档

```text
不要执行 Git 写操作。请按总手册提交当前子阶段完成报告：目标、产物与精确路径、验证命令及结果、需求映射、风险、遗留项、学习卡、建议暂存路径和提交消息。检查秘密、个人数据、生成物、无关修改和文档代码不同步。最后明确询问我是否“批准归档”。
```

## P07 用户批准本地归档后

```text
我批准归档当前报告列出的精确文件。只执行本地 Git 暂存、复核 staged diff 和一次聚焦提交；不要 push、tag、部署或扩大范围。提交后报告 commit ID、实际文件、验证证据和工作区剩余修改。若实际差异超出报告，停止并重新向我说明。
```
